Quantum Query Algorithms

How powerful is $\mathsf{BQP}$? In this chapter we look at the evidence from below: algorithms that beat their classical counterparts. As in the Relativization chapter, we work in a model where lower bounds can actually be proved, namely query complexity. The proofs in the last two technical chapters do not depend on this one.

Guiding Question

Is there any problem where quantum computers provably beat classical ones?

The query model and phase kickback

Proving that $\mathsf{BPP}\ne\mathsf{BQP}$ is far beyond current techniques (the Main Theorem chapter explains why). So, as with relativization in CS455, we study a simpler model where we can prove lower bounds. The input is a function $f:\{0,1\}^n\to\{0,1\}$ given as a black box, and we count only how many times an algorithm evaluates it.

Definition (Query algorithms; the oracle gate $O_f$)

A classical query algorithm (deterministic or randomized) may ask "what is $f(x)$?" for any $x$; each question costs one query. A quantum query algorithm is a quantum circuit over $\mathcal G$ together with an extra gate $O_f$ on $n+1$ qubits, defined by $$O_f\ket x\ket b = \ket x\ket{b\oplus f(x)}\qquad(x\in\{0,1\}^n,\ b\in\{0,1\}),$$ and each use of $O_f$ costs one query. $O_f$ is a classical gate (see definition), so it is unitary.

If $f$ is computed by a Boolean circuit $D$, then Bennett's Uncomputation Lemma builds $O_f$ out of $\mathcal G$, with scratch qubits that start and end in $\ket{0^s}$. So query algorithms turn into real algorithms. Here it matters that the scratch is clean, because the algorithms below rely on interference across different inputs $x$ (the clean-oracle exercise shows what goes wrong otherwise). The key trick turns a function value into a sign, which is exactly where interference can act on it:

Lemma (Phase Kickback Lemma)

Let $\ket- = H\ket1 = \tfrac{1}{\sqrt2}(\ket0-\ket1)$. Then for every $x\in\{0,1\}^n$, $\;O_f\ket x\ket- = (-1)^{f(x)}\ket x\ket-$.

Proof. $O_f\ket x\ket- = \tfrac1{\sqrt2}\big(\ket x\ket{f(x)} - \ket x\ket{1\oplus f(x)}\big)$. If $f(x)=0$ this is $\ket x\ket-$. If $f(x)=1$ it is $\tfrac1{\sqrt2}\big(\ket x\ket1 - \ket x\ket0\big) = -\ket x\ket-$. ∎

We also need one identity about signs, which is the reason Hadamard transforms are so useful:

Lemma (Character Sum Lemma)

For every $u\in\{0,1\}^n$, $\displaystyle\sum_{x\in\{0,1\}^n}(-1)^{x\cdot u} = \begin{cases}2^n & u = 0^n,\\ 0 & u\ne 0^n.\end{cases}$

Proof. The sum factors: $\sum_x(-1)^{x_1u_1+\cdots+x_nu_n} = \prod_{i=1}^n\big(\sum_{x_i\in\{0,1\}}(-1)^{x_iu_i}\big) = \prod_{i=1}^n\big(1+(-1)^{u_i}\big)$. Each factor is $2$ if $u_i=0$ and $0$ if $u_i = 1$. ∎

Both algorithms below use the same circuit. Only the analysis differs.

Let's compute the state once and for all. With $\ket{\psi_0} = \ket{0^n}\ket1$:

  • $\ket{\psi_1} = \Big(2^{-n/2}\sum_{x}\ket x\Big)\ket-$, by the Hadamard Transform Lemma on the top register and $H\ket1 = \ket-$ on the bottom.
  • $\ket{\psi_2} = \Big(2^{-n/2}\sum_x(-1)^{f(x)}\ket x\Big)\ket-$, by phase kickback (the Phase Kickback Lemma) and linearity.
  • $\ket{\psi_3} = \Big(\sum_{y}a_y\ket y\Big)\ket-$ where $\displaystyle a_y = \frac{1}{2^n}\sum_{x\in\{0,1\}^n}(-1)^{f(x)+x\cdot y}$, by the Hadamard Transform Lemma again.

Measuring the top register gives $y$ with probability $|a_y|^2$. (The bottom qubit is in a product state with the top register, so it doesn't affect these probabilities.) In path language, $a_y$ sums $2^n$ paths, one through each $x$, each with weight $\pm 2^{-n}$. The sign $(-1)^{f(x)}$ is the function value, "kicked back" into the phase.

Deutsch–Jozsa: constant or balanced?

Problem. We are promised that $f$ is either constant (all outputs equal) or balanced (exactly half the outputs are $1$). Decide which.

Theorem (Deutsch–Jozsa 1992)

The circuit above, with one query, outputs $y = 0^n$ with probability $1$ if $f$ is constant and with probability $0$ if $f$ is balanced.

Proof. $a_{0^n} = 2^{-n}\sum_x(-1)^{f(x)}$. If $f$ is constant this is $\pm1$. If $f$ is balanced, $2^{n-1}$ terms are $+1$ and $2^{n-1}$ are $-1$, so it is $0$. The probability of outcome $0^n$ is $|a_{0^n}|^2$. ∎
Proposition (Deterministic lower bound)

Every deterministic classical algorithm that always solves the Deutsch–Jozsa problem makes at least $2^{n-1}+1$ queries on some input.

Proof. Use an adversary. Answer $0$ to each of the algorithm's first $2^{n-1}$ distinct queries. At that point the constant-$0$ function is consistent with every answer. So is a balanced function: at least $2^{n-1}$ points haven't been queried, so set $f=1$ on exactly $2^{n-1}$ of them and $0$ everywhere else. The algorithm must give the same answer in both cases, so it is wrong on one of them. ∎
Remark (But randomness nearly matches it)

A randomized algorithm can query $k$ random points and answer "constant" if all the answers agree. For balanced $f$ it errs with probability $2\cdot2^{-k}$, so $k=3$ queries already give error $\le\tfrac14$. So Deutsch–Jozsa separates exact quantum computation from deterministic computation, but not from $\mathsf{BPP}$-style computation. It is still a perfect showcase of interference: $2^n$ paths cancel exactly.

Bernstein–Vazirani: learning a hidden string

Problem. We are promised that $f(x) = s\cdot x \bmod 2$ for an unknown string $s\in\{0,1\}^n$. Find $s$.

Theorem (Bernstein–Vazirani 1993)

The same circuit, with one query, outputs exactly $y = s$ with probability $1$.

Proof. Since $s\cdot x + x\cdot y \equiv x\cdot(s\oplus y)\pmod 2$, the Character Sum Lemma gives $a_y = 2^{-n}\sum_x(-1)^{x\cdot(s\oplus y)}$, which is $1$ if $y = s$ and $0$ otherwise. ∎
Proposition (Classical lower bound, even with randomness)

Any classical randomized algorithm that makes $k$ queries and outputs $s$ with probability at least $\tfrac23$ for every $s$ must have $k\ge n$. ($n$ queries suffice: query $e_1,\dots,e_n$.)

Proof. First fix the algorithm's coin flips, so it becomes a deterministic algorithm $A$. Each query $A$ makes depends only on the answers to earlier queries, so $A$'s output is determined by the sequence of $k$ answer bits. Hence $A$ produces at most $2^k$ different outputs over all $s$, and it is correct for at most $2^k$ of the $2^n$ possible strings $s$. If $s$ is uniformly random, $\Pr_s[A\text{ correct}]\le 2^{k-n}$. A randomized algorithm is a probability distribution over such $A$'s, so averaging gives $\Pr_{\text{coins},\,s}[\text{correct}]\le2^{k-n}$. But if the algorithm succeeds with probability $\ge\tfrac23$ for every $s$, then this average is $\ge\tfrac23$. So $2^{k-n}\ge\tfrac23$, giving $k\ge n-\log_2\tfrac32 > n-1$. ∎
Remark (Intuition)

A classical query returns one bit about $s$, so learning $n$ bits takes $n$ queries. The quantum query is made on a superposition of all $x$, and the final Hadamard transform converts the resulting pattern of signs $(-1)^{s\cdot x}$ into the single string $s$. Every path to a wrong $y$ cancels. This is a polynomial ($1$ vs. $n$) separation from randomized algorithms. Applying the idea recursively gives a superpolynomial separation (Bernstein–Vazirani 1997).

A guided tour of stronger results

The two algorithms above are the "hello world" of quantum algorithms. Here is what the same ideas, pushed much further, are known to achieve. We state these without proof.

Fact (Separations and limits)
  1. Simon (1994). There is a promise problem about functions $f:\{0,1\}^n\to\{0,1\}^n$ that quantum algorithms solve with $O(n)$ queries but every randomized algorithm needs $\Omega(2^{n/2})$ queries. Consequently there is an oracle $A$ with $\mathsf{BPP}^A\ne\mathsf{BQP}^A$.
  2. Shor (1994). Factoring integers and computing discrete logarithms can be done in quantum polynomial time. The decision version of factoring ("does $N$ have a prime factor $\le k$?") is in $\mathsf{BQP}$, but it is not known to be in $\mathsf{BPP}$, and it is not believed to be $\mathsf{NP}$-complete.
  3. Grover (1996) and BBBV (1997). Searching for a marked item among $N$ takes $O(\sqrt N)$ quantum queries, and Bennett, Bernstein, Brassard and Vazirani showed that $\Omega(\sqrt N)$ queries are necessary. So "brute-force" search gets only a quadratic speed-up, and relative to a random oracle $A$, $\mathsf{NP}^A\not\subseteq\mathsf{BQP}^A$. This is evidence that quantum computers cannot solve $\mathsf{NP}$-complete problems efficiently.
  4. Raz–Tal (2018). There is an oracle $A$ with $\mathsf{BQP}^A\not\subseteq\mathsf{PH}^A$. Relative to some oracle, quantum computers can do things the entire polynomial hierarchy cannot.
Remark (Omitted details)

Proofs of the known separations are beyond the scope of two lectures. Simon's algorithm is a short extension of this chapter (same circuit, with $f$'s output on $n$ qubits); see Arora–Barak, Chapter 10. Shor's algorithm needs the quantum Fourier transform and continued fractions (Nielsen–Chuang Ch. 5; Arora–Barak Ch. 10). Grover and the BBBV lower bound are in Nielsen–Chuang Ch. 6. The original papers are D. Simon, SIAM J. Comput. 26(5), 1997; P. Shor, SIAM J. Comput. 26(5), 1997; L. Grover, STOC 1996; Bennett et al., SIAM J. Comput. 26(5), 1997; R. Raz and A. Tal, STOC 2019 / J. ACM 2022.

Remark (How to read oracle results)

As with Baker–Gill–Solovay in CS455, an oracle separation is not a proof that $\mathsf{BPP}\ne\mathsf{BQP}$. It shows that any proof of $\mathsf{BPP}=\mathsf{BQP}$ would have to use non-relativizing techniques, and it gives intuition for what quantum computers are good at: finding hidden global structure (periods, hidden strings, symmetries) through interference, not unstructured search. The next two chapters go the other way. They prove, unconditionally, that quantum power is limited.

Exercises

Exercise

Run the Deutsch–Jozsa circuit on an $f$ that is neither constant nor balanced, with $|f^{-1}(1)| = w$. What is the probability of outcome $0^n$?

$a_{0^n} = 2^{-n}\big((2^n-w) - w\big) = 1 - 2w/2^n$, so the probability is $(1-2w/2^n)^2$. It is $1$ at $w\in\{0,2^n\}$ and $0$ at $w=2^{n-1}$.

Exercise (Why clean oracles matter)

Suppose that, instead of $O_f$, we used a "dirty" oracle that also leaves a copy of $x$ in $n$ scratch qubits: $\ket x\ket{0^n}\ket b\mapsto\ket x\ket x\ket{b\oplus f(x)}$. Show that Bernstein–Vazirani then outputs a uniformly random $y$.

After the query the state is $2^{-n/2}\sum_x(-1)^{s\cdot x}\ket x\ket x\ket-$. After $H^{\otimes n}$ on the first register it is $2^{-n}\sum_{x,y}(-1)^{s\cdot x+x\cdot y}\ket y\ket x\ket-$. Now each $\ket{y}\ket{x}$ is a different basis state for each $x$, so nothing cancels (see remark). $\Pr[y] = \sum_x 2^{-2n} = 2^{-n}$ for every $y$.

Summary

  • Phase kickback turns $f(x)$ into a sign $(-1)^{f(x)}$, and the Hadamard transform then makes those signs interfere.
  • Deutsch–Jozsa: 1 query vs. $2^{n-1}+1$ deterministic queries. Bernstein–Vazirani: 1 query vs. $n$ queries, even for randomized algorithms.
  • Simon and Shor give exponential speed-ups; Grover's quadratic speed-up for search is optimal. The evidence: quantum computers are good at hidden structure, not at $\mathsf{NP}$-completeness.
  • These are query-model results. Unconditional separations of $\mathsf{BQP}$ from $\mathsf{BPP}$ are out of reach, and the Main Theorem chapter shows why.
