$\mathsf{BQP}\subseteq\mathsf{PSPACE}$

We now turn to the other half of our result: limits on what quantum computers can do. In this chapter we prove that $\mathsf{BQP}\subseteq\mathsf{PSPACE}$. To do this we prove the Path-Sum Lemma, which says that every amplitude is a signed count of computation paths. We will use the same lemma to prove the Main Theorem in the next chapter.

The goal, and the obvious approach

Fix $L\in\mathsf{BQP}$, solved by a uniform circuit family $\mathcal C = (C_0, C_1, \dots)$ over $\mathcal G$ (see definition). On an input $x$ of length $n$, a classical simulation has to decide whether $p_{C_n}(x)\ge\tfrac23$ or $p_{C_n}(x)\le\tfrac13$. Let $m$, $T$ and $h$ be the number of qubits, gates and Hadamard gates of $C_n$. All three are polynomial in $n$. In this chapter and the next, we write $$z = x0^{m-n}\quad\text{for the starting basis string, so that}\quad p_{C_n}(x) = \sum_{y:\,y_m=1}\big|\amp{y}{C_n}{z}\big|^2$$ by the definition of acceptance probability.

The obvious approach is to do what the quantum computer does: store all $2^m$ amplitudes and multiply the vector by each gate. This is called a Schrödinger-style simulation. We can even do the arithmetic exactly, since after $t$ gates, $h_t$ of which are Hadamards, every amplitude is a whole number times $2^{-h_t/2}$. This shows $\mathsf{BQP}\subseteq\mathsf{EXP}$, but it uses $2^m$ space, because it writes down all exponentially many amplitudes. To do better we use a Feynman-style simulation: we never store the state, and we compute one amplitude at a time as a sum over paths (see lemma), keeping only the current path in memory. This is the same trade as in Savitch’s theorem: we use more time and recompute things in order to use less space.

The Path-Sum Lemma

The Sum-over-Paths Lemma writes an amplitude as a sum over sequences $z_0\to z_1\to\dots\to z_T$ of $m$-bit strings, but almost all of those sequences have weight $0$. For our gate set, we can say exactly which paths are nonzero. A classical gate sends a basis string to one basis string (see definition). A Hadamard gate on qubit $j$ sends it to two basis strings, one for each value $c$ of the new bit $j$, with weight $(-1)^{w_j c}/\sqrt2$ (see lemma). So a nonzero path is determined by the $h$ bits chosen at the Hadamard gates, and its sign depends on how many times a Hadamard went from $1$ to $1$. The following classical procedure follows one path.

Definition (The path-following procedure $\mathrm{Follow}$)

Let $C$ be a circuit over $\mathcal G$ on $m$ qubits with gates $g_1,\dots,g_T$, where $h$ of them are Hadamard gates. For a start string $z\in\{0,1\}^m$ and a choice string $b\in\{0,1\}^h$, define $\mathrm{Follow}(z,b) = (w,\varphi)$ by:

def $\mathrm{Follow}(z, b)$:
$w \gets z$; $\ \varphi\gets 0$; $\ i\gets 0$
for $t = 1,\dots,T$:
if $g_t = X$ on qubit $j$: $\ w_j\gets 1-w_j$
if $g_t = \CNOT$ with control $c$, target $j$: $\ w_j\gets w_j\oplus w_c$
if $g_t = \TOF$ with controls $c,c'$, target $j$: $\ w_j\gets w_j\oplus(w_c\wedge w_{c'})$
if $g_t = H$ on qubit $j$: $\ i\gets i+1$; $\ \varphi\gets\varphi\oplus(w_j\wedge b_i)$; $\ w_j\gets b_i$
return $(w,\varphi)$

We write $w(z,b)$ and $\varphi(z,b)$ for the two outputs: the path’s endpoint and its sign bit. Given $C$, $\mathrm{Follow}$ runs in time $O(T+m)$ and space $O(m+\log T)$.

In words: $b_i$ is the bit chosen at the $i$-th Hadamard gate (which branch the path takes), $w$ is where the path currently is, and $\varphi$ is the parity of the number of $1\to1$ Hadamard steps. These are the negative edges in the path tree of $HH\ket0$.

Lemma (Path-Sum Lemma; cf. Dawson et al. 2005)

For every circuit $C$ over $\mathcal G$ with $h$ Hadamard gates and every $z\in\{0,1\}^m$, $$C\ket z \;=\; \frac{1}{2^{h/2}}\sum_{b\in\{0,1\}^h}(-1)^{\varphi(z,b)}\,\ket{w(z,b)} .$$ Equivalently, for every $y\in\{0,1\}^m$: $\displaystyle\amp{y}{C}{z} = \frac{1}{2^{h/2}}\sum_{b\,:\,w(z,b) = y}(-1)^{\varphi(z,b)}$.

Proof. We prove a slightly stronger statement by induction on the number of gates. For $0\le t\le T$, let $C_t = U_t\cdots U_1$ be the first $t$ gates, let $h_t$ be the number of Hadamards among them, and let $\mathrm{Follow}_t(z,b) = (w_t(z,b),\varphi_t(z,b))$ be the result of running $\mathrm{Follow}$ only up to gate $t$, with $b\in\{0,1\}^{h_t}$. We claim $$C_t\ket z = 2^{-h_t/2}\sum_{b\in\{0,1\}^{h_t}}(-1)^{\varphi_t(z,b)}\ket{w_t(z,b)}. \tag{$\ast$}$$ The case $t=T$ is the lemma.

Base case, $t=0$. $C_0 = I$ and $h_0=0$. The sum has one term (the empty $b$), with $\varphi=0$ and $w = z$, so both sides equal $\ket z$.

Step when $g_{t+1}$ is a classical gate ($X$, CNOT or Toffoli). By the definitions of applying a gate and of classical gates, $U_{t+1}\ket w = \ket{w'}$, where $w'$ is $w$ updated exactly as in the $X$, CNOT and Toffoli lines of $\mathrm{Follow}$. Applying $U_{t+1}$ to each term of $(\ast)$ turns $\ket{w_t(z,b)}$ into $\ket{w_{t+1}(z,b)}$, and $h$ and $\varphi$ don’t change. That gives $(\ast)$ for $t+1$.

Step when $g_{t+1} = H$ on qubit $j$. By the definition of applying a gate and the Hadamard Formula, for every string $w$, $$U_{t+1}\ket w = \frac{1}{\sqrt2}\sum_{c\in\{0,1\}}(-1)^{w_j\cdot c}\,\ket{w[j\gets c]} .$$ Applying this to each term of $(\ast)$ gives $$C_{t+1}\ket z = \frac{1}{2^{(h_t+1)/2}}\sum_{b\in\{0,1\}^{h_t}}\;\sum_{c\in\{0,1\}}(-1)^{\varphi_t(z,b)\,\oplus\,(w_t(z,b)_j\,\wedge\, c)}\;\ket{w_t(z,b)[j\gets c]}.$$ Now treat the pair $(b,c)$ as one string $b' = bc\in\{0,1\}^{h_t+1}$. The $H$ line of $\mathrm{Follow}$ does exactly this at the $(h_t+1)$-th Hadamard: it reads $c = b'_{h_t+1}$, updates $\varphi\gets\varphi\oplus(w_j\wedge c)$, and sets $w_j\gets c$. So the $b'$ term has sign $(-1)^{\varphi_{t+1}(z,b')}$ and basis state $\ket{w_{t+1}(z,b')}$, and $h_{t+1} = h_t+1$. That is $(\ast)$ for $t+1$.

The second form of the lemma comes from grouping the terms by their endpoint $w(z,b)$. ∎

Corollary (Signed Counts)

For every $y$, $\amp{y}{C}{z} = A_y/2^{h/2}$, where $$A_y \;=\; \#\{b: w(z,b)=y,\ \varphi(z,b)=0\} \;-\; \#\{b: w(z,b)=y,\ \varphi(z,b)=1\}$$ is an integer with $|A_y|\le 2^h$. In words: an amplitude is (up to a fixed scaling) the number of positive paths to $y$ minus the number of negative paths to $y$.

Example ($HH\ket0$ using $\mathrm{Follow}$)

Let $C = H, H$ on one qubit, so $h=2$ and $b = b_1b_2$. In $\mathrm{Follow}(0,b)$, the first $H$ gives $\varphi = 0\wedge b_1 = 0$ and $w = b_1$. The second gives $\varphi = b_1\wedge b_2$ and $w = b_2$.

BQP ⊆ PSPACE

Theorem (Bernstein–Vazirani 1993)

$\mathsf{BQP}\subseteq\mathsf{PSPACE}$.

Proof idea. By the Signed Counts Corollary, the acceptance probability is a sum of squares of signed counts. Each count is a sum of $2^h$ terms, and we can compute each term in polynomial time from $b$ alone. So we can compute the whole thing with nested loops, reusing the same space each time, just like in the proof of $\mathsf{PP}\subseteq\mathsf{PSPACE}$.

Proof. Let $L\in\mathsf{BQP}$ via $\mathcal C = (C_0,C_1,\dots)$. Fix an input $x$ with $|x|=n$, let $C = C_n$, and let $z = x0^{m-n}$.

Step 1 (a formula for $p_C(x)$). By the definition of acceptance probability and the Signed Counts Corollary, $$p_C(x) = \sum_{y:\,y_m=1}\Big(\frac{A_y}{2^{h/2}}\Big)^2 = \frac{S}{2^h},\qquad\text{where } S = \sum_{y:\,y_m=1}A_y^2 .$$ (The amplitudes are real, so $|\cdot|^2$ is just squaring.) So $p_C(x)>\tfrac12$ exactly when $S>2^{h-1}$.

Step 2 (the algorithm). We define $M'$ as follows:

def $M'(x)$:
compute $C = C_{|x|}$ (uniformity); read off $m, T, h$; set $z\gets x0^{m-|x|}$
$S\gets 0$
for all $y\in\{0,1\}^m$ with $y_m = 1$:
$A\gets 0$
for all $b\in\{0,1\}^h$:
$(w,\varphi)\gets\mathrm{Follow}(z,b)$
if $w = y$: $\ A\gets A + (-1)^{\varphi}$
$S\gets S + A^2$
if $S > 2^{h-1}$: accept
else: reject

Correctness. By the Signed Counts Corollary, the inner loop ends with $A = A_y$, so at the end $S = \sum_{y_m=1}A_y^2 = 2^h p_C(x)$. If $x\in L$, then $p_C(x)\ge\tfrac23>\tfrac12$ and we accept. If $x\notin L$, then $p_C(x)\le\tfrac13$ and we reject.

Space. The description of $C$ takes $\mathrm{poly}(n)$ bits. The loop variables $y$ and $b$ take $m$ and $h$ bits. Each call to $\mathrm{Follow}$ uses $O(m+\log T)$ bits, and every call reuses the same space. Since $|A|\le 2^h$, the counter $A$ needs $h+2$ bits. Since $S\le 2^{m-1}\cdot 2^{2h}$, $S$ needs at most $m+2h$ bits. All of this is polynomial in $n$, so $L\in\mathsf{PSPACE}$. (The running time is about $2^{m+h}\cdot\mathrm{poly}(n)$, which is exponential, but that’s fine.) ∎

Remark (Why this works)

We never need the whole state. We only need one number, $p_C(x)$, which is a sum of terms we can compute one at a time. Each term is easy to compute, because between Hadamard gates a circuit over $\mathcal G$ is just a reversible Boolean circuit. And an exponentially long sum fits in polynomial space as long as we add up the terms as we go, just like in $\mathsf{PP}\subseteq\mathsf{PSPACE}$. So the exponential size of the quantum state costs the simulation time, but not space.

Looking ahead

The number we computed, $S = \sum_{y_m=1}A_y^2$, is built from counts of things we can check in polynomial time. Counting is exactly what $\mathsf{PP}$ is good at (see remark). The one thing in the way of a $\mathsf{PP}$ simulation is the square. The acceptance probability of a PTM is a linear function of path counts, but $S$ is quadratic in the $A_y$. The fix is to expand the square, which turns a sum over paths into a sum over pairs of paths. That is where the proof of the Main Theorem starts in the next chapter.

Summary

  • Path-Sum Lemma: $\amp yCz = 2^{-h/2}\sum_{b:\,w(z,b)=y}(-1)^{\varphi(z,b)}$. Each path is a choice string $b$, and $\mathrm{Follow}$ computes its endpoint and sign in polynomial time.
  • So an amplitude is a signed count: the number of positive paths minus the number of negative paths, times $2^{-h/2}$.
  • Storing the whole state takes $2^m$ space. Adding up paths one at a time takes only polynomial space, so $\mathsf{BQP}\subseteq\mathsf{PSPACE}$.
