Unitary Gates and Circuits

In the last chapter we defined quantum states. In this chapter we define the operations a quantum computer can apply to them, and we combine these operations into quantum circuits. We also prove the Hadamard Formula, which describes what the Hadamard gate does to a basis state. We will use it in almost every later proof.

Why operations must be unitary

In quantum mechanics, a state changes by a linear map. That map has to turn every state into a state, so it has to keep the norm of every vector equal to $1$. The matrices that do this are exactly the unitary ones.

Definition (Unitary matrix)

A square complex matrix $U$ is unitary if $U^\dagger U = I$. Equivalently, the columns of $U$ are orthonormal, and $U^{-1} = U^\dagger$. (A real unitary matrix is an orthogonal matrix: $U^TU = I$.)

Fact (Unitary = norm-preserving)

A square matrix $U$ satisfies $\|Uv\| = \|v\|$ for all vectors $v$ if and only if $U$ is unitary.

Proof. ($\Leftarrow$) $\|Uv\|^2 = (Uv)^\dagger(Uv) = v^\dagger U^\dagger U v = v^\dagger v = \|v\|^2$. ($\Rightarrow$) This is a standard linear algebra exercise: plugging in $v = e_i$, $v=e_i+e_j$ and $v = e_i+\mathrm{i}\,e_j$ shows that the columns of $U$ are orthonormal. ∎
Remark (Quantum computation is reversible)

Every unitary has an inverse ($U^\dagger$), so a quantum computer can never “forget” information. The classical AND gate sends both $00$ and $01$ to $0$, so it has no inverse and can’t be used as a quantum gate directly. This raises the question of whether quantum computers can even simulate classical ones. We answer it in the BQP and Reversible Computation chapter.

Single-qubit gates

Definition (Pauli $X$, Pauli $Z$, Hadamard $H$)

$$X = \begin{pmatrix}0&1\\1&0\end{pmatrix},\quad Z = \begin{pmatrix}1&0\\0&-1\end{pmatrix},\quad H = \frac{1}{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}.$$ On basis states, for $a\in\{0,1\}$: $X\ket a = \ket{1-a}$ (the NOT gate), and $Z\ket a = (-1)^a\ket a$.

Each of these is unitary. For example, the columns of $H$, $\tfrac1{\sqrt2}(1,1)^T$ and $\tfrac1{\sqrt2}(1,-1)^T$, are orthonormal. The most important of the three is $H$, so we write down exactly what it does:

Lemma (Hadamard Formula)

For every bit $a\in\{0,1\}$, $$H\ket a = \frac{1}{\sqrt2}\sum_{c\in\{0,1\}}(-1)^{a\cdot c}\ket c .$$ In words: $H$ turns a bit into an equal mix of both possible output bits, each with amplitude $\pm\tfrac1{\sqrt2}$. The sign is negative only when the input bit and the output bit are both 1.

Proof. Read off the columns of $H$: $H\ket0 = \tfrac{1}{\sqrt2}(\ket0+\ket1)$ and $H\ket1 = \tfrac1{\sqrt2}(\ket0-\ket1)$. The only minus sign is at $a=c=1$. ∎
Example ($H$ undoes itself)

By the Hadamard Formula, $H\ket0 = \ket+$ and $H\ket1 = \ket-$ (see the $\ket{\pm}$ example). Now apply $H$ to $\ket+$ and use linearity: $$H\ket+ = \tfrac1{\sqrt2}\big(H\ket0 + H\ket1\big) = \tfrac12\big(\ket0 + \ket1 + \ket0 - \ket1\big) = \ket 0.$$ The two $\ket1$ terms have opposite signs and cancel, while the two $\ket0$ terms add up. In the same way, $H\ket- = \ket1$. So $HH = I$, and $H$ can tell $\ket+$ and $\ket-$ apart perfectly, even though measuring them directly gives the same fair coin flip. This is the simplest example of interference, which is the topic of the next chapter.

Applying a gate to some qubits of a register

A gate like $H$ is a $2\times2$ matrix, so it acts on one qubit. A circuit, however, works on a register of $m$ qubits. The way that this works is quite simple. We just have the the gate change on the bits it touches and all the other bits stay the same.

For example, we can apply $H$ to qubit 1 of $\ket{10}$. Qubit 1 holds the bit $1$ and $H\ket1 = \tfrac1{\sqrt2}(\ket0-\ket1)$ by the Hadamard Formula. Putting each value back in position 1, with qubit 2 still $0$, gives $$\tfrac1{\sqrt2}\big(\ket{00}-\ket{10}\big).$$

If the register is in a superposition of several basis states, we do this to each basis state separately and simply add up the results keeping the amplitudes. Here is this exact idea written formally.

Definition (Applying a $k$-qubit gate to chosen qubits)

Let $G$ be a $k$-qubit gate (a $2^k\times2^k$ unitary), and pick $k$ different qubit positions $j_1,\dots,j_k$ out of $\{1,\dots,m\}$ These are the bits that will be affected. For a string $z\in\{0,1\}^m$ and new bits $c\in\{0,1\}^k$, write $z[j\gets c]$ for the string $z$ with the bits in positions $j_1,\dots,j_k$ replaced by $c_1,\dots,c_k$. We write $G_{[j_1,\dots,j_k]}$ for $G$ applied to those qubits. On a basis state it does $$G_{[j_1,\dots,j_k]}\ket z = \sum_{c\in\{0,1\}^k}\amp{c}{G}{z_{j_1}\cdots z_{j_k}}\,\ket{z[j\gets c]},$$

CNOT, Toffoli, and classical gates

Definition (CNOT and Toffoli)

For bits $a,b,c$ (where $\oplus$ is XOR): $$\CNOT\ket{a,b} = \ket{a,\;b\oplus a}, \qquad \TOF\ket{a,b,c} = \ket{a,\;b,\;c\oplus(a\wedge b)}.$$ CNOT (“controlled NOT”) flips the bit $b$ (the target bit) when the bit $a$ (the control bit) is $1$. Both of these are their own inverses.

$X$, CNOT and Toffoli have a property that makes them classical gates which is that they are a 1-1 mapping of the basis states onto themselves. Note that $H$ does not have this property.

Definition (Classical gate)

A $k$-qubit gate $G$ is classical if there is a permutation $\pi$ of $\{0,1\}^k$ with $G\ket u = \ket{\pi(u)}$ for every $u$. Its matrix is a permutation matrix, which is always unitary.

This matters because a classical gate applied to a basis state doesn't use any of what makes quantum computation stronger than classical computation. So, all of the interference which we discussed in our intro chapter comes from Hadamard gates. We will now look at a simple example of the power that hadamard has.

Example (Bell state)

Start with $\ket{\psi_0}=\ket{00}$. Applying $H$ to qubit 1 gives $$\ket{\psi_1} = \tfrac1{\sqrt2}\big(\ket{00} + \ket{10}\big).$$ Then apply CNOT with control qubit 1 and target qubit 2. This flips the second bit of each basis state whose first bit is $1$: $$\ket{\psi_2} = \tfrac1{\sqrt2}\big(\ket{00} + \ket{11}\big) = \ket{\Phi^+}.$$ Now the bits are entangled as they are always equal.

Quantum circuits and our gate set

Definition (Quantum circuit)

A quantum circuit $C$ on $m$ qubits over a finite gate set is a sequence of gates $g_1,\dots,g_T$. Each $g_t$ is a gate from the set, together with a list of distinct qubits it acts on. Let $U_t$ be the $2^m\times2^m$ unitary of $g_t$. So, the final unitary matrix is: $$C = U_T\,U_{T-1}\cdots U_1,$$ $T$ is the size of the circuit, and $h$ is the number of its gates that are Hadamard gates. For basis strings $x, y\in\{0,1\}^m$, $\amp yCx$ is the amplitude of $\ket y$ in $C\ket x$.

Note that we only ever measure at the end of a circuit. This is because if we measured somewhere in the middle, we change the state of the qubits. This doesn't lose any computational power though because of the principle of deferred measurement which tells us that any measurement in the middle of a circuit can be moved to the end simply by copying any qubit we want to measure into a fresh qubit with a CNOT. See Nielsen–Chuang.

Definition (Our gate set $\mathcal G$)

In these notes, quantum circuits use the gate set $$\mathcal G = \{\,H,\;X,\;\CNOT,\;\TOF\,\}.$$ Every gate in $\mathcal G$ except $H$ is classical, and every matrix entry is in $\{0,\pm1,\pm\tfrac1{\sqrt2}\}$. Furthermore, all the circuits in $\mathcal G$ will only ever produce real amplitudes.

We use this gate set because it is simple and it keeps the proof of $\mathsf{BQP}\subseteq\mathsf{PSPACE}$ clean. We also don't lose computation power.

Fact (Hadamard + Toffoli is universal; Shi 2003, Aharonov 2003)

Let $\mathcal G'$ be any standard universal gate set. Every circuit over $\mathcal G'$ with $T$ gates can be simulated by a circuit over $\mathcal G$ with $\mathrm{poly}(T,\log(1/\varepsilon))$ gates whose acceptance probability is within $\varepsilon$ of the original.

This means that despite covering them briefly we do not need complex numbers to prove the results we want in complexity theory.

Many coins at once

Applying $H$ to each of $n$ qubits is written $H^{\otimes n}$.

Lemma (Uniform Superposition Lemma)

$$H^{\otimes n}\ket{0^n} = \frac{1}{2^{n/2}}\sum_{y\in\{0,1\}^n}\ket y .$$

Proof. $H^{\otimes n}\ket{0^n} = H\ket0\otimes\cdots\otimes H\ket0 = \ket+^{\otimes n}$. Expanding $\big(\tfrac1{\sqrt2}(\ket0+\ket1)\big)^{\otimes n}$ by bilinearity gives one term $2^{-n/2}\ket{y_1\cdots y_n}$ for each $y\in\{0,1\}^n$. ∎

Measuring this after $n$ Hadamard gates gives us a uniformly random $n$-bit string.

Summary

  • Quantum operations are unitary. That means they keep norms the same, and they are always reversible.
  • $H\ket a = \tfrac1{\sqrt2}\sum_c(-1)^{ac}\ket c$. Hadamard is where the extra computational power of quantum computation comes from.
  • Classical gates ($X$, CNOT, Toffoli) just rearrange basis states so they never create interference.
