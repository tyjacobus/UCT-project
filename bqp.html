$\mathsf{BQP}$ and Reversible Computation

We now have everything we need to define $\mathsf{BQP}$, the quantum version of $\mathsf{BPP}$. In this chapter we define it and then prove the lower half of our result: $\mathsf{P}\subseteq\mathsf{BPP}\subseteq\mathsf{BQP}$. The main difficulty is that quantum computation has to be reversible, but normal Boolean circuits are not.

The class BQP

A quantum algorithm takes a classical input $x\in\{0,1\}^n$, puts it in the first $n$ qubits, sets every other qubit (the “ancilla” qubits) to $\ket0$, runs a circuit, and measures one qubit to get its answer. We use the last qubit as the answer qubit, so it never overlaps with the input.

Definition (Acceptance probability)

Let $C$ be a circuit on $m$ qubits and $x\in\{0,1\}^n$ with $n\le m$. Running $C$ on $x$ means starting in $\ket{x0^{m-n}}$, applying $C$, and measuring qubit $m$. $C$ accepts if the result is $1$. By the measurement rule, the acceptance probability is $$p_C(x) \;=\; \sum_{y\in\{0,1\}^m:\;y_m = 1}\big|\amp{y}{C}{x0^{m-n}}\big|^2 .$$

Definition ($\mathsf{BQP}$, bounded-error quantum polynomial time; Bernstein–Vazirani 1993)

A quantum circuit family $\mathcal C = (C_0, C_1, C_2,\dots)$ solves a language $L$ with error $\epsilon$ if $$\forall x\in L,\quad \Pr[C_{|x|}(x)\text{ accepts}]\ge 1-\epsilon, \qquad\qquad \forall x\notin L,\quad \Pr[C_{|x|}(x)\text{ accepts}]\le\epsilon,$$ where $\Pr[C(x)\text{ accepts}] = p_C(x)$. Then $$\mathsf{BQP} = \{L \mid \exists \text{ polynomial-time uniform circuit family } \mathcal C \text{ over } \mathcal G \text{ solving } L \text{ with error } \tfrac13\}.$$ Here $\mathcal G = \{H,X,\CNOT,\TOF\}$ is our gate set (see definition). Polynomial-time uniform means the same thing as for Boolean circuits (see definition): a deterministic polynomial-time TM, given $1^n$, outputs the list of gates of $C_n$ and the qubits each one acts on. In particular, $C_n$ has $m(n)$ qubits and $T(n)$ gates, both polynomial in $n$.

Compare this with the definition of $\mathsf{BPP}$. It is the same definition, with the same error $\tfrac13$. The only difference is that the PTM is replaced by a uniform family of quantum circuits.

Remark (The definition is robust; omitted details)

As with $\mathsf{BPP}$, the error $\tfrac13$ can be lowered to $2^{-\mathrm{poly}(n)}$. We run several independent copies of $C_n$ on separate qubits, compute the majority of their answers reversibly, and apply Hoeffding’s inequality, just like in the Two-sided Error Reduction theorem of Probabilistic Time Complexity 2. Also, by the universality fact, using any other standard gate set instead of $\mathcal G$ gives the same class. We only sketch these facts; see Bernstein–Vazirani (1997) or Arora–Barak, Chapter 10. None of our proofs depend on them.

Making classical circuits reversible

To prove $\mathsf{P}\subseteq\mathsf{BQP}$, we want to run a normal Boolean circuit $D$ (with AND, OR and NOT gates) on a quantum computer. The problem (see remark) is that AND and OR are not reversible. The fix is to never overwrite anything. Each gate writes its output into a fresh qubit that starts as $\ket0$. The Toffoli gate computes AND this way: $\TOF\ket{a,b,0} = \ket{a,b,a\wedge b}$.

Lemma (Reversible Simulation Lemma)

Let $D$ be a Boolean circuit with $n$ inputs and $s$ gates (AND, OR, NOT; fan-in at most 2; any fan-out), whose gates, in topological order, compute the bits $g_1(x),\dots,g_s(x)$. There is a circuit $R_D$ over $\{X,\CNOT,\TOF\}$ on $n+s$ qubits with at most $6s$ gates such that for every $x\in\{0,1\}^n$, $$R_D\ket{x}\ket{0^s} = \ket{x}\ket{g(x)},\qquad\text{where } g(x) = g_1(x)\,g_2(x)\cdots g_s(x).$$ Also, $R_D$ can be computed from $D$ in polynomial time.

Proof. (If a gate’s two inputs are the same wire $a$, it just computes $a$, so we can use a single $\CNOT$ from $a$ into its fresh qubit. So we can assume each AND or OR gate reads two different wires.) Give gate $i$ of $D$ its own qubit $n+i$, starting at $\ket0$. Go through the gates in topological order. When we reach gate $i$, its input wires (input bits or earlier gate qubits) already hold the right values. Then:
  • $\mathrm{NOT}(a)$: apply $\CNOT$ from $a$ to qubit $n+i$ (so it holds $a$), then $X$ on qubit $n+i$ (so it holds $\neg a$).
  • $\mathrm{AND}(a,b)$: apply $\TOF$ with controls $a,b$ and target $n+i$, which then holds $0\oplus(a\wedge b) = a\wedge b$.
  • $\mathrm{OR}(a,b) = \neg(\neg a\wedge\neg b)$: apply $X$ to $a$ and $b$, then $\TOF$ into $n+i$, then $X$ to $a$ and $b$ again (to restore them), then $X$ on $n+i$. That is $6$ gates.
Each step only permanently changes qubit $n+i$, and every wire it reads ends up unchanged. So by induction on $i$, after gate $i$ the register holds $x,\,g_1(x),\dots,g_i(x),\,0,\dots,0$. Fan-out is free, because a wire can be used as a control any number of times. All the gates are classical, so on basis states this is exactly the classical computation. ∎

For a single basis state, the Reversible Simulation Lemma is enough. But quantum algorithms run circuits on superpositions, and then the extra bits $g(x)$, called “garbage”, cause problems. By linearity, $$R_D\Big(\sum_x\alpha_x\ket x\Big)\ket{0^s} = \sum_x\alpha_x\ket x\ket{g(x)} .$$ Now the garbage is entangled with $x$. It records which path was taken, so by the interference principle it stops different values of $x$ from cancelling later. Bennett’s trick from 1973 removes the garbage: compute, copy the answer, and then run the computation backwards.

Lemma (Bennett’s Uncomputation Lemma)

Let $D$ be a Boolean circuit with $n$ inputs and $s$ gates that computes $f:\{0,1\}^n\to\{0,1\}$ (the output is the last gate, so $f = g_s$). There is a circuit $B_D$ over $\{X,\CNOT,\TOF\}$ on $n+s+1$ qubits, with at most $12s+1$ gates and computable from $D$ in polynomial time, such that for all $x\in\{0,1\}^n$ and $b\in\{0,1\}$: $$B_D\,\ket{x}\ket{0^s}\ket{b} \;=\; \ket{x}\ket{0^s}\ket{b\oplus f(x)} .$$

Proof. Let $B_D = R_D^{-1}\cdot \CNOT_{[n+s,\;n+s+1]}\cdot R_D$, where $R_D$ is from the Reversible Simulation Lemma and $R_D^{-1}$ is the gates of $R_D$ in reverse order. (Each of $X$, CNOT and Toffoli is its own inverse, so this really is the inverse.) Follow a basis state through the three steps: $$\ket x\ket{0^s}\ket b\;\xrightarrow{\;R_D\;}\;\ket x\ket{g(x)}\ket b\;\xrightarrow{\;\CNOT\;}\;\ket x\ket{g(x)}\ket{b\oplus f(x)}\;\xrightarrow{\;R_D^{-1}\;}\;\ket x\ket{0^s}\ket{b\oplus f(x)}.$$ The first step is the Reversible Simulation Lemma ($R_D$ doesn’t touch the last qubit). The second copies the last scratch bit, $g_s(x) = f(x)$, into the last qubit. In the third, $R_D^{-1}$ only acts on the first $n+s$ qubits, and it sends $\ket x\ket{g(x)}$ back to $\ket x\ket{0^s}$, since $R_D$ sends $\ket x\ket{0^s}$ to $\ket x\ket{g(x)}$. The gate count is $6s+1+6s$. ∎
Remark (Why this works)

By linearity, Bennett’s circuit acts on a superposition like this: $$B_D\sum_{x,b}\alpha_{x,b}\ket x\ket{0^s}\ket b = \sum_{x,b}\alpha_{x,b}\ket x\ket{0^s}\ket{b\oplus f(x)} .$$ The scratch register is $\ket{0^s}$ in every branch, so it doesn’t record anything, and different branches can still cancel later. We couldn’t just “reset” the garbage to $0$, because that is not reversible. Measuring it doesn’t work either, because the measurement result is itself a record of which path was taken.

P ⊆ BQP and BPP ⊆ BQP

Theorem ($\mathsf{P}\subseteq\mathsf{BQP}$)

Every language in $\mathsf{P}$ is in $\mathsf{BQP}$. In fact, the circuits accept with probability exactly $1$ or $0$.

Proof. Let $L\in\mathsf{P}$. By the Efficient TM to Efficient Circuit theorem, there is a polynomial-time uniform family of Boolean circuits $D_n$ of size $s(n) = \mathrm{poly}(n)$ that decide $L$ on inputs of length $n$. Let $C_n = B_{D_n}$ from Bennett’s Uncomputation Lemma, on $m = n+s+1$ qubits. $C_n$ only uses gates from $\mathcal G$, and it can be printed in polynomial time: first print $D_n$, then apply the polynomial-time constructions from the two lemmas above. Running $C_n$ on $x$ starts at $\ket{x}\ket{0^s}\ket0$ and ends at the basis state $\ket{x}\ket{0^s}\ket{L(x)}$, where $L(x) = 1$ if $x\in L$ and $0$ otherwise. So $p_{C_n}(x) = 1$ if $x\in L$ and $0$ otherwise. ∎

For $\mathsf{BPP}$ we also need coin flips. As we saw at the end of the last chapter, a Hadamard gate on a fresh qubit acts like a coin flip, as long as we never let its branches cancel.

Theorem ($\mathsf{BPP}\subseteq\mathsf{BQP}$)

Every language in $\mathsf{BPP}$ is in $\mathsf{BQP}$. More precisely, for every polynomial-time PTM $M$ there is a polynomial-time uniform circuit family $\mathcal C = (C_0, C_1, \dots)$ over $\mathcal G$ with $p_{C_n}(x) = \Pr[M(x)\text{ accepts}]$ for every $x$.

Proof. Use the random-tape view (see the Background Review): there is a polynomial $r(n)$ and a deterministic polynomial-time TM $V(x,\rho)$, with $\rho\in\{0,1\}^{r(|x|)}$, such that $\Pr[M(x)\text{ accepts}] = \Pr_{\rho}[V(x,\rho)\text{ accepts}]$. Write $r = r(n)$. By the Efficient TM to Efficient Circuit theorem applied to $V$ on inputs of length $n+r$, there are uniform Boolean circuits $D_n$ of size $s = \mathrm{poly}(n)$ with $D_n(x,\rho) = V(x,\rho)$.

Split the $m = n + r + s + 1$ qubits into four registers: input $x$ ($n$ qubits), coins ($r$), scratch ($s$) and answer ($1$). Let $C_n$ be:

  1. apply $H$ to each of the $r$ coin qubits;
  2. apply $B_{D_n}$ (Bennett’s Uncomputation Lemma), using “input + coins” as its $n+r$ input qubits.

We follow the state. It starts as $\ket x\ket{0^r}\ket{0^s}\ket0$. By the Uniform Superposition Lemma, step 1 gives $$\frac{1}{2^{r/2}}\sum_{\rho\in\{0,1\}^r}\ket x\ket\rho\ket{0^s}\ket0 .$$ By Bennett’s Uncomputation Lemma and linearity, step 2 gives $$\frac{1}{2^{r/2}}\sum_{\rho\in\{0,1\}^r}\ket x\ket\rho\ket{0^s}\ket{V(x,\rho)} .$$ Different values of $\rho$ give different basis states (they differ in the coin register), so each basis state $\ket{x\,\rho\,0^s\,V(x,\rho)}$ has amplitude exactly $2^{-r/2}$, and no two terms combine. By the definition of acceptance probability, $$p_{C_n}(x) = \sum_{\rho:\,V(x,\rho)=1}\big(2^{-r/2}\big)^2 = \frac{\#\{\rho: V(x,\rho) = 1\}}{2^r} = \Pr[M(x)\text{ accepts}].$$ So the $\tfrac23$ / $\tfrac13$ guarantee of $M$ carries over to $C_n$. Uniformity follows as in the proof of $\mathsf{P}\subseteq\mathsf{BQP}$. ∎

The coins act like normal random bits because nothing ever applies $H$ to the coin register again. The coin register is a permanent record of which path was taken, so the $2^r$ branches never cancel. To get more power than $\mathsf{BPP}$, a quantum algorithm has to let branches cancel, and then removing garbage becomes essential.

Summary

  • $\mathsf{BQP}$ is defined exactly like $\mathsf{BPP}$, but with a uniform family of quantum circuits over $\mathcal G$ instead of a PTM.
  • Toffoli gates let us make any classical circuit reversible, but this leaves garbage.
  • Bennett’s trick (compute, copy, uncompute) removes the garbage, so classical computations can be used inside quantum algorithms. This gives $\mathsf{P}\subseteq\mathsf{BPP}\subseteq\mathsf{BQP}$.
