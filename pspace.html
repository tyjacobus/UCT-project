Warm-up: BQP ⊆ PSPACE

Amplitudes are signed counts of paths, and a classical machine can add them up one at a time.

Where this page sits. This is the first upper bound on quantum power. It introduces the main lemma that the centerpiece proof (Page 9) also uses.
  • You will learn: two ways to simulate a quantum circuit classically (Schrödinger: store the state; Feynman: sum over paths), the path-sum lemma for our gate set, and a polynomial-space simulation.
  • Prerequisites: Lemma 4.4 (Hadamard formula), Definitions 4.6, 4.8, 4.10, Lemma 5.3 (sum over paths), Definitions 6.1–6.2. From 455: reusing space, as in Savitch's theorem.

§1The goal, and the obvious approach

Fix $L\in\mathsf{BQP}$, decided by a uniform family $\{C_n\}$ over $\mathcal G$ (Definition 6.2). On input $x$ of length $n$, a classical simulator must decide whether $p_{C_n}(x)\ge\tfrac23$ or $p_{C_n}(x)\le\tfrac13$. Write $m$, $T$, $h$ for the number of qubits, gates and Hadamard gates of $C_n$. All three are polynomial in $n$. Throughout this page and the next, write $$z = x0^{m-n}\quad\text{for the initial basis string, so that}\quad p_{C_n}(x) = \sum_{y:\,y_m=1}\big|\amp{y}{C_n}{z}\big|^2 \qquad(\text{Definition 6.1}).$$

The obvious approach is to do what the quantum computer "does": keep the whole state vector and multiply it by each gate.

Proposition 8.1 ($\mathsf{BQP}\subseteq\mathsf{EXP}$, by Schrödinger-style simulation)

Every language in $\mathsf{BQP}$ can be decided by a deterministic algorithm in time (and space) $2^{\mathrm{poly}(n)}$.

Proof. Compute $C_n$ (polynomial time, by uniformity). Store the current state as $2^m$ numbers. To make the arithmetic exact, note that after $t$ gates, of which $h_t$ are Hadamards, every amplitude has the form $A/2^{h_t/2}$ with $A$ an integer. This holds initially ($h_0 = 0$, entries $0$ and $1$). A classical gate only permutes the entries. A Hadamard on qubit $j$ replaces the amplitudes $\alpha,\alpha'$ of each pair $w[j\gets0], w[j\gets1]$ by $(\alpha\pm\alpha')/\sqrt2$, which keeps the form with $h_{t}+1$. Since the state is a unit vector, $|A|\le 2^{h_t/2}$, so each integer has $O(h)$ bits. Each gate takes $2^m\cdot\mathrm{poly}(n)$ steps, and at the end we compute $p = \sum_{y_m=1}A_y^2/2^h$ exactly and accept if and only if $p>\tfrac12$. ∎

This is honest, but it uses $2^m$ space. (The universe-sized vector of Remark 3.10 really is being written down.) To do better we use the other way of thinking about the computation:

Schrödinger: store the state

Keep all $2^m$ amplitudes and update them gate by gate. Time $\approx 2^m T$, space $\approx 2^m$.

Feynman: sum over histories

Never store the state. Compute one amplitude at a time as a sum over paths (Lemma 5.3), keeping only the current path. Time exponential, space polynomial.

This is the same time-for-space trade as in Savitch's theorem: recompute instead of remember.

§2The path-sum lemma

Lemma 5.3 writes an amplitude as a sum over sequences $z_0\to z_1\to\dots\to z_T$ of $m$-bit strings, but nearly all of those sequences have weight $0$. For our gate set we can say exactly which paths are nonzero: a classical gate sends a basis string to one basis string (Definition 4.8), and a Hadamard on qubit $j$ sends it to two, one for each value $c$ of the new bit $j$, with weight $(-1)^{w_j c}/\sqrt2$ (Lemma 4.4). So a nonzero path is determined by the $h$ bits chosen at the Hadamard gates, and its sign records how many times a Hadamard went from $1$ to $1$. The following classical procedure follows one such path.

Definition 8.2 (The path-following procedure $\mathrm{Follow}$)

Let $C$ be a circuit over $\mathcal G$ on $m$ qubits with gates $g_1,\dots,g_T$, of which $h$ are Hadamard gates. For a start string $z\in\{0,1\}^m$ and a choice string $b\in\{0,1\}^h$, define $\mathrm{Follow}(z,b) = (w,\varphi)$ by:

  1. $w\gets z$; $\;\varphi\gets 0$; $\;i\gets0$.
  2. For $t = 1,\dots,T$:
    1. if $g_t = X$ on qubit $j$: flip $w_j$;
    2. if $g_t = \CNOT$ with control $c$ and target $j$: $w_j\gets w_j\oplus w_c$;
    3. if $g_t = \TOF$ with controls $c,c'$ and target $j$: $w_j\gets w_j\oplus(w_c\wedge w_{c'})$;
    4. if $g_t = H$ on qubit $j$: $i\gets i+1$; $\;\varphi\gets\varphi\oplus(w_j\wedge b_i)$; $\;w_j\gets b_i$.
  3. Return $(w,\varphi)$.

We write $w(z,b)$ and $\varphi(z,b)$ for the two outputs: the path's endpoint and its sign bit. $\mathrm{Follow}$ runs in time $O(T+m)$ and space $O(m+\log T)$, given $C$.

In words: $b_i$ is the output bit chosen at the $i$-th Hadamard ("which branch did the path take?"), $w$ is where the path currently is, and $\varphi$ is the parity of the number of $1\to1$ Hadamard steps, the negative edges in the tree of Example 5.4.

Lemma 8.3 (Path-sum lemma; cf. Dawson et al. 2005)

For every circuit $C$ over $\mathcal G$ with $h$ Hadamard gates and every $z\in\{0,1\}^m$, $$C\ket z \;=\; \frac{1}{2^{h/2}}\sum_{b\in\{0,1\}^h}(-1)^{\varphi(z,b)}\,\ket{w(z,b)} .$$ Equivalently, for every $y\in\{0,1\}^m$: $\displaystyle\amp{y}{C}{z} = \frac{1}{2^{h/2}}\sum_{b\,:\,w(z,b) = y}(-1)^{\varphi(z,b)}$.

Proof. We prove a stronger statement by induction on the number of gates. For $0\le t\le T$, let $C_t = U_t\cdots U_1$ be the first $t$ gates, let $h_t$ be the number of Hadamards among them, and let $\mathrm{Follow}_t(z,b) = (w_t(z,b),\varphi_t(z,b))$ be the result of running $\mathrm{Follow}$ through gate $t$ only, with $b\in\{0,1\}^{h_t}$. We claim $$C_t\ket z = 2^{-h_t/2}\sum_{b\in\{0,1\}^{h_t}}(-1)^{\varphi_t(z,b)}\ket{w_t(z,b)}. \tag{$\ast$}$$ The case $t=T$ is the lemma.

Base case, $t=0$. $C_0 = I$ and $h_0=0$. The sum has a single term (the empty $b$) with $\varphi=0$ and $w = z$, so both sides equal $\ket z$.

Step, when $g_{t+1}$ is a classical gate ($X$, CNOT or TOF). By Definitions 4.6 and 4.8, $U_{t+1}\ket w = \ket{w'}$, where $w'$ is $w$ updated exactly as in step 2(a)–(c) of $\mathrm{Follow}$. Apply $U_{t+1}$ to $(\ast)$ term by term (linearity): each $\ket{w_t(z,b)}$ becomes $\ket{w_{t+1}(z,b)}$, while $h_{t+1} = h_t$ and $\varphi_{t+1} = \varphi_t$. That gives $(\ast)$ for $t+1$.

Step, when $g_{t+1} = H$ on qubit $j$. By Definition 4.6 and Lemma 4.4, for every string $w$, $$U_{t+1}\ket w = \frac{1}{\sqrt2}\sum_{c\in\{0,1\}}(-1)^{w_j\cdot c}\,\ket{w[j\gets c]} .$$ Apply this to each term of $(\ast)$: $$C_{t+1}\ket z = \frac{1}{2^{(h_t+1)/2}}\sum_{b\in\{0,1\}^{h_t}}\;\sum_{c\in\{0,1\}}(-1)^{\varphi_t(z,b)\,\oplus\,(w_t(z,b)_j\,\wedge\, c)}\;\ket{w_t(z,b)[j\gets c]}.$$ Now rename the pair $(b,c)$ as one string $b' = bc\in\{0,1\}^{h_t+1}$. Step 2(d) of $\mathrm{Follow}$ does exactly this at the $(h_t+1)$-th Hadamard: it reads $c = b'_{h_t+1}$, updates $\varphi\gets\varphi\oplus(w_j\wedge c)$, and sets $w_j\gets c$. So the sign and the basis state of the $b'$ term are $(-1)^{\varphi_{t+1}(z,b')}$ and $\ket{w_{t+1}(z,b')}$, and $h_{t+1} = h_t+1$. That is $(\ast)$ for $t+1$.

Finally, the "equivalently" form comes from collecting the terms of the sum by their endpoint $w(z,b)$. ∎

Corollary 8.4 (Amplitudes are signed counts)

For every $y$, $\amp{y}{C}{z} = A_y/2^{h/2}$, where $$A_y \;=\; \#\{b: w(z,b)=y,\ \varphi(z,b)=0\} \;-\; \#\{b: w(z,b)=y,\ \varphi(z,b)=1\}$$ is an integer with $|A_y|\le 2^h$. In words: an amplitude is (up to a fixed scaling) the number of positive paths to $y$ minus the number of negative paths to $y$.

Example 8.5 ($HH\ket0$ through $\mathrm{Follow}$)

$C = H, H$ on one qubit, so $h=2$ and $b = b_1b_2$. $\mathrm{Follow}(0,b)$: the first $H$ gives $\varphi = 0\wedge b_1 = 0$ and $w = b_1$. The second gives $\varphi = b_1\wedge b_2$ and $w = b_2$.

§3BQP ⊆ PSPACE

Theorem 8.6 (Bernstein–Vazirani 1993)

$\mathsf{BQP}\subseteq\mathsf{PSPACE}$.

Proof idea. By Corollary 8.4, the acceptance probability is a sum of squares of signed counts. Each count is a sum of $2^h$ terms, and each term can be computed in polynomial time from $b$ alone. So we evaluate the whole expression with nested loops, reusing space between iterations, just as in the proof that $\mathsf{PP}\subseteq\mathsf{PSPACE}$ (Proposition 2.6).

Proof. Let $L\in\mathsf{BQP}$ via $\{C_n\}$. Fix an input $x$ with $|x|=n$, let $C = C_n$, and let $z = x0^{m-n}$.

Step 1 (a formula for $p_C(x)$). By Definition 6.1 and Corollary 8.4, $$p_C(x) = \sum_{y:\,y_m=1}\Big(\frac{A_y}{2^{h/2}}\Big)^2 = \frac{S}{2^h},\qquad\text{where } S = \sum_{y:\,y_m=1}A_y^2 .$$ (Amplitudes are real by Corollary 8.4, so $|\cdot|^2$ is just squaring.) Hence $p_C(x)>\tfrac12$ if and only if $S>2^{h-1}$.

Step 2 (the algorithm). On input $x$:

  1. Compute the description of $C = C_n$ (uniformity: polynomial time, hence polynomial space). Read off $m$, $T$, $h$, and set $z = x0^{m-n}$.
  2. $S\gets 0$.
  3. For each $y\in\{0,1\}^m$ with $y_m = 1$:
    1. $A\gets 0$.
    2. For each $b\in\{0,1\}^h$: compute $(w,\varphi) = \mathrm{Follow}(z,b)$; if $w = y$, then $A\gets A + (-1)^\varphi$.
    3. $S\gets S + A^2$.
  4. Accept if and only if $S>2^{h-1}$.

Correctness. By Corollary 8.4, the inner loop leaves $A = A_y$, so at the end $S = \sum_{y_m=1}A_y^2 = 2^h p_C(x)$. If $x\in L$ then $p_C(x)\ge\tfrac23>\tfrac12$ and we accept. If $x\notin L$ then $p_C(x)\le\tfrac13$ and we reject.

Space. The description of $C$ takes $\mathrm{poly}(n)$ bits. The loop variables $y$ and $b$ take $m$ and $h$ bits. Each call to $\mathrm{Follow}$ uses $O(m+\log T)$ bits, and the same space is reused by every call. Since $|A|\le 2^h$, the counter $A$ needs $h+2$ bits. Since $S\le 2^{m-1}\cdot 2^{2h}$, $S$ needs at most $m+2h$ bits. All of this is polynomial in $n$, so $L\in\mathsf{PSPACE}$. (The running time is about $2^{m+h}\cdot\mathrm{poly}(n)$, which is exponential, but that's allowed.) ∎

Why this works
  1. We never need the whole state. The answer depends on one number, $p_C(x)$, and that number is a sum of terms we can produce one at a time.
  2. Each path is cheap. Following one path is a classical, polynomial-time computation, because between Hadamards a circuit over $\mathcal G$ is just a reversible Boolean circuit.
  3. Exponential sums fit in polynomial space, as long as you add terms as you go rather than storing them. This is the same insight as $\mathsf{PP}\subseteq\mathsf{PSPACE}$.

The exponential size of the quantum state (Remark 3.10) is real, but it is a time cost for the simulator, not a space cost.

§4Looking ahead: can we do better than PSPACE?

The quantity we computed, $S = \sum_{y_m=1}A_y^2$, is a polynomial-size expression in counts of polynomial-time checkable objects. Counting is exactly what $\mathsf{PP}$ is good at (Page 2). So it is natural to hope that a $\mathsf{PP}$ machine can decide whether $S>2^{h-1}$. There is one obstacle: the square. A probabilistic machine's acceptance probability is a linear function of path counts, but $S$ is quadratic in the $A_y$. The fix is to expand the square, which turns a sum over paths into a sum over pairs of paths (Exercise 8.B). That is the starting point of the centerpiece proof on the next page.

Exercises

Exercise 8.A Use $\mathrm{Follow}$ to compute $C\ket{00}$ for the which-path circuit of Example 5.5 ($H$ on qubit 1, CNOT from 1 to 2, $H$ on qubit 1). Explain from the table why nothing cancels.
Show solution

$h=2$. After the first $H$: $w = b_1 0$. After the CNOT: $w = b_1b_1$. At the second $H$ (on qubit 1): $\varphi = b_1\wedge b_2$ and $w = b_2 b_1$. So $b = 00,01,10,11$ give endpoints $00, 10, 01, 11$ with signs $+,+,+,-$. All four endpoints are distinct, so every $A_y$ is $\pm1$ and no two paths can cancel. The second qubit (the second bit of $w$) is a copy of $b_1$, which is exactly the which-path record of Remark 5.6. So $C\ket{00} = \tfrac12(\ket{00}+\ket{10}+\ket{01}-\ket{11})$. (Pick "Which-path information" in the explorer to see this.)

Exercise 8.B (Preview of Lemma 9.3.) Show that $\displaystyle S = \sum_{b,b'\in\{0,1\}^h}\big[w(z,b) = w(z,b')\text{ and }w(z,b)_m = 1\big]\,(-1)^{\varphi(z,b)+\varphi(z,b')}$, where $[\cdot]$ is $1$ if the condition holds and $0$ otherwise.
Show solution

By Corollary 8.4, $A_y = \sum_b[w(z,b)=y](-1)^{\varphi(z,b)}$, so $A_y^2 = \sum_{b,b'}[w(z,b)=y]\,[w(z,b')=y]\,(-1)^{\varphi(z,b)+\varphi(z,b')}$. Sum over $y$ with $y_m=1$ and swap the order of summation. For a fixed pair $(b,b')$, the only $y$ that can contribute is $y = w(z,b)$, and it does so exactly when $w(z,b') = w(z,b)$ and $w(z,b)_m = 1$.

Exercise 8.C Corollary 8.4 says $|A_y|\le 2^h$, but in fact $|A_y|\le 2^{h/2}$. Why? What does that say about how much cancellation a typical circuit has?
Show solution

$|\amp yCz|\le1$ because $C\ket z$ is a unit vector, so $|A_y| = 2^{h/2}|\amp yCz|\le 2^{h/2}$. There are $2^h$ paths in total, so at most a $2^{-h/2}$ fraction of them can "survive" cancellation at any single endpoint. Interference is the rule, not the exception.

Takeaways
  • Path-sum lemma: over $\mathcal G$, $\amp yCz = 2^{-h/2}\sum_{b:\,w(z,b)=y}(-1)^{\varphi(z,b)}$. A path is a choice string $b$, and $\mathrm{Follow}$ computes its endpoint and sign in polynomial time.
  • An amplitude is a signed count: #positive paths minus #negative paths, times $2^{-h/2}$.
  • Schrödinger simulation uses $2^m$ space. Feynman simulation adds the paths one at a time in polynomial space, so $\mathsf{BQP}\subseteq\mathsf{PSPACE}$.
  • The remaining obstacle to $\mathsf{PP}$ is the square $|\cdot|^2$. Expanding it gives a sum over pairs of paths.
