Quantum vs. Randomized Computation

In this chapter we describe randomized and quantum computation in the same way, using vectors and matrices. Written like this, the only real difference between them is that quantum amplitudes can be negative. We also introduce the “sum over paths” view of a computation, which is the main idea behind both of our upper-bound proofs.

Randomized computation is linear algebra too

Think of a randomized algorithm on an $m$-bit memory. At any moment its state is a probability distribution over $\{0,1\}^m$, which is a vector $p\in\R^{2^m}$ with $p_z\ge0$ and $\sum_z p_z = 1$. Each step changes the distribution linearly: if the step moves from memory contents $z$ to $z'$ with probability $M_{z',z}$, then the new distribution is $Mp$.

Definition (Stochastic matrix)

A real matrix $M$ is stochastic if all its entries are nonnegative and each column sums to $1$. These are exactly the matrices that turn every probability vector into a probability vector. The basic randomized gate is the coin flip $$F = \begin{pmatrix}\tfrac12&\tfrac12\\[2pt]\tfrac12&\tfrac12\end{pmatrix},$$ which replaces a bit with a new random bit. Classical gates (permutation matrices) are also stochastic.

Example (Flip a coin twice vs. apply $H$ twice)

Randomized. Start with the bit $0$, i.e. $p = (1,0)^T$.
$Fp = (\tfrac12,\tfrac12)^T$, and $F(Fp) = (\tfrac12,\tfrac12)^T$.
Once we add randomness, more coin flips can never remove it.

Quantum. Start with $\ket0$.
$H\ket0 = \ket+$, which looks like a fair coin if we measure it.
But $H\ket+ = \ket 0$ (see example): the outcome is $0$ with certainty.

The quantum “coin” was flipped twice and the result is no longer random. The next section explains where the randomness went by following each path of the computation.

Sum over paths

A computation that applies $U_1$, then $U_2$, and so on up to $U_T$, to a basis state $\ket x$ can be drawn as a tree. From $x$ it branches to every $z_1$ with $(U_1)_{z_1,x}\ne0$, from each $z_1$ to every $z_2$, and so on. Each final entry is a sum over root-to-leaf paths. This is just matrix multiplication written out:

Lemma (Sum-over-Paths Lemma)

Let $U_1,\dots,U_T$ be $2^m\times2^m$ matrices and $x,y\in\{0,1\}^m$. Then $$\big(U_T\cdots U_1\big)_{y,x} \;=\; \sum_{z_1,\dots,z_{T-1}\in\{0,1\}^m}\;\prod_{t=1}^{T}\,(U_t)_{z_t,\,z_{t-1}}, \qquad\text{where } z_0 = x,\; z_T = y .$$ We call $x=z_0\to z_1\to\cdots\to z_T=y$ a path and the product its weight.

Proof. Induction on $T$. For $T=1$ there is nothing to prove. For $T>1$, by the definition of matrix multiplication, $(U_T\cdot U_{T-1}\cdots U_1)_{y,x} = \sum_{z_{T-1}}(U_T)_{y,z_{T-1}}\,(U_{T-1}\cdots U_1)_{z_{T-1},x}$. Expand the second factor using the induction hypothesis. ∎

The Sum-over-Paths Lemma works for any matrices. The two models differ in what the weights look like:

  • Randomized ($U_t$ stochastic): the weight of a path is the probability of taking it, so the lemma is just the law of total probability: $\Pr[\text{end at } y] = \sum_{\text{paths}}\Pr[\text{path}]$. Every term is $\ge0$, so the terms can only add up.
  • Quantum ($U_t$ unitary, applied to $\ket x$): the lemma gives the amplitude $\amp{y}{C}{x}$ as a sum of path weights, and these weights can be negative. Then $$\Pr[\text{see } y] = \Big|\sum_{\text{paths } x\to y}\text{weight}(\text{path})\Big|^2,\qquad\text{which is }\textbf{not}\text{ the same as}\quad \sum_{\text{paths}}|\text{weight}|^2 .$$ Paths with opposite signs cancel each other (destructive interference), and paths with the same sign add up (constructive interference). This is called interference.
Example (The paths of $HH\ket0$)

Group the four paths by where they end: $$\amp{0}{HH}{0} = \tfrac12 + \tfrac12 = 1,\qquad \amp{1}{HH}{0} = \tfrac12 - \tfrac12 = 0 .$$ For the coin $F$, the same tree has every edge weighted $\tfrac12$, every path weighted $+\tfrac14$, and each endpoint gets $\tfrac14+\tfrac14 = \tfrac12$. The two trees are the same except for the sign on one edge, and that sign is what makes the paths to $\ket1$ cancel.

Remark (How quantum algorithms work)

A quantum algorithm branches into exponentially many paths, just like a randomized algorithm, but it sets up the signs so that the paths leading to wrong answers cancel out. The Sum-over-Paths Lemma also hints at how to simulate a quantum computer on a normal computer: add up the path weights one at a time. That is the idea behind both upper bounds in these notes.

Interference needs paths that end in the same place

Cancellation is easy to break. Here is the most important way it can break, and it will matter in every later chapter.

Example (“Which-path” information stops interference)

Take the circuit $H, H$ on qubit 1 from the coin-versus-Hadamard example, and add a CNOT between the two $H$ gates that copies qubit 1 into a second qubit:

$\ket{\psi_1} = \tfrac1{\sqrt2}(\ket{00}+\ket{10})$, and $\ket{\psi_2} = \tfrac1{\sqrt2}(\ket{00}+\ket{11})$ (a Bell state). Applying $H$ to qubit 1 (see definition): $$\ket{\psi_3} = \tfrac12\big(\ket{00} + \ket{10}\big) + \tfrac12\big(\ket{01} - \ket{11}\big).$$ Now $\Pr[\text{qubit 1 reads }1] = \tfrac14+\tfrac14 = \tfrac12$. Without the CNOT, qubit 1 was always $0$.

The paths explain why. The two paths that lead to “qubit 1 $=1$” still have weights $+\tfrac12$ and $-\tfrac12$, but now they end at different basis states, $\ket{10}$ and $\ket{11}$, because qubit 2 recorded which branch was taken. The Sum-over-Paths Lemma only adds up weights of paths that end at the same string $y$, so these two paths never cancel.

Remark (The interference principle)

Two paths can only cancel if they end in the same basis state of the whole register. Any record of which branch was taken, in any qubit, even one we never look at, keeps the paths apart and stops them from cancelling. Measuring a qubit in the middle of the computation has the same effect, because the measurement result is such a record.

This is why we will need to “uncompute” scratch work (Bennett’s Uncomputation Lemma), and why, in the proof of the Main Theorem, a pair of paths only counts when both end at the same string (the Two-Path Lemma).

Coins are a special case

The interference principle also tells us how a quantum computer can imitate a coin flip. Apply $H$ to a fresh qubit in state $\ket0$, and after that only use the qubit as a control (never apply another $H$ to it). Its value stays recorded in the register, so its two branches can never cancel, and it acts exactly like a fair random bit. We use this idea in the proof that $\mathsf{BPP}\subseteq\mathsf{BQP}$.

Summary

  • Randomized computation uses nonnegative weights and quantum computation uses signed weights. Everything else is the same.
  • An amplitude is a sum of path weights. Probabilities just add up, but amplitudes add up and are then squared, so paths can cancel.
  • Paths only cancel if they end at the same basis state. Any record of which path was taken stops the cancellation.
