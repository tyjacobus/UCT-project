Background Review

This chapter reviews the background we need. Most of it (Turing machines, $\mathsf{P}$, $\mathsf{NP}$, $\mathsf{PSPACE}$, $\mathsf{EXP}$, Boolean circuits and $\mathsf{BPP}$) was covered in CS455, so we only recall it briefly. The new parts are complex vectors, tensor products and the class $\mathsf{PP}$. You can skim this chapter now and come back to it when a later chapter links here.

Complex vectors and inner products

A complex number is $\alpha = a + bi$ with $a,b\in\R$ and $i^2=-1$. Its conjugate is $\bar\alpha = a - bi$, and its modulus is $|\alpha| = \sqrt{a^2+b^2}$. The only identity we really need is $$|\alpha|^2 = \alpha\,\bar\alpha .$$ For a real number this is just $|\alpha|^2 = \alpha^2$. That is the only case we need for the main theorem, because our gate set (see definition) only produces real amplitudes.

Definition (Conjugate transpose, inner product, norm)

For a complex matrix $A$, its conjugate transpose $A^\dagger$ is obtained by transposing $A$ and conjugating every entry: $(A^\dagger)_{ij} = \overline{A_{ji}}$. For $u, v\in\C^N$ (column vectors), the inner product and norm are $$\langle u, v\rangle = u^\dagger v = \sum_{i=1}^N \overline{u_i}\, v_i, \qquad \|v\| = \sqrt{\langle v,v\rangle} = \Big(\sum_{i=1}^N |v_i|^2\Big)^{1/2}.$$ A unit vector has $\|v\|=1$. The standard basis vectors $e_1,\dots,e_N$ are orthonormal: $\langle e_i, e_j\rangle = 1$ if $i=j$ and $0$ otherwise.

For real vectors, this is just the usual dot product and length.

Tensor products

Quantum computing uses the tensor product to put systems side by side. If one system is described by a vector in $\C^N$ and another by a vector in $\C^M$, the two together are described by a vector in $\C^{NM}$, with one coordinate for every pair of indices.

Definition (Tensor (Kronecker) product)

For $u\in\C^N$ and $v\in\C^M$, the tensor product $u\otimes v\in\C^{NM}$ has coordinates indexed by pairs $(i,j)$, listed in lexicographic order: $$(u\otimes v)_{(i,j)} = u_i\, v_j.$$ Similarly, for an $N\times N$ matrix $A$ and an $M\times M$ matrix $B$, $A\otimes B$ is the $NM\times NM$ matrix with $(A\otimes B)_{(i,j),(i',j')} = A_{ii'}\,B_{jj'}$. In block form, $A\otimes B = \begin{pmatrix} A_{11}B & \cdots & A_{1N}B\\ \vdots & & \vdots \\ A_{N1}B & \cdots & A_{NN}B\end{pmatrix}$.

Example

$\begin{pmatrix}a\\b\end{pmatrix}\otimes\begin{pmatrix}c\\d\end{pmatrix} = \begin{pmatrix}ac\\ad\\bc\\bd\end{pmatrix}$, with coordinates indexed by the pairs $(1,1),(1,2),(2,1),(2,2)$. For instance $\begin{pmatrix}1\\0\end{pmatrix}\otimes\begin{pmatrix}0\\1\end{pmatrix} = \begin{pmatrix}0\\1\\0\\0\end{pmatrix}$: the tensor product of two standard basis vectors is a standard basis vector.

Fact (Properties of $\otimes$)
  1. Bilinear: $(\alpha u + \beta u')\otimes v = \alpha(u\otimes v) + \beta(u'\otimes v)$, and the same in the second slot.
  2. Basis to basis: $e_i\otimes e_j = e_{(i,j)}$.
  3. Acts factor by factor: $(A\otimes B)(u\otimes v) = (Au)\otimes(Bv)$, and $(A\otimes B)(C\otimes D) = (AC)\otimes(BD)$.
  4. Norms multiply: $\|u\otimes v\| = \|u\|\,\|v\|$.
  5. Associative: $(u\otimes v)\otimes w = u\otimes(v\otimes w)$, so we can drop parentheses.
Proof sketch. Each item follows by comparing coordinates. For example, for item 3: $\big((A\otimes B)(u\otimes v)\big)_{(i,j)} = \sum_{i',j'} A_{ii'}B_{jj'}u_{i'}v_{j'} = \big(\sum_{i'}A_{ii'}u_{i'}\big)\big(\sum_{j'}B_{jj'}v_{j'}\big) = (Au)_i (Bv)_j$. For item 4, $\sum_{i,j}|u_iv_j|^2 = \sum_i |u_i|^2\sum_j|v_j|^2$. ∎

Randomized classes: BPP and PP

Recall from Probabilistic Time Complexity 1 that a probabilistic TM (PTM) is a TM with extra coin-flip states. We can also use the random-tape view: a deterministic TM $M(x,r)$ that gets the random bits $r$ as a second input. We only care about polynomial-time PTMs that always halt, and we can assume that on inputs of length $n$ the machine reads exactly $p(n)$ random bits for some polynomial $p$ (by adding unused bits if needed). Then $$\Pr[M(x)\text{ accepts}] = \Pr_{r\sim\{0,1\}^{p(|x|)}}[M(x,r)\text{ accepts}],$$ which is just the fraction of random strings $r$ that make $M$ accept.

Definition ($\mathsf{BPP}$, recalled from CS455)

$$\mathsf{BPTIME}(t(n)) = \{L \mid \exists\text{ PTM } M \text{ solving } L \text{ in time } O(t(n)) \text{ and error } \tfrac13\},$$ $$\mathsf{BPP} = \bigcup_{k\in\mathbb N}\mathsf{BPTIME}(n^k).$$ Recall that $M$ solves $L$ with error $\epsilon$ if $$\forall x\in L,\ \Pr[M(x)\text{ accepts}]\ge 1-\epsilon, \qquad \forall x\notin L,\ \Pr[M(x)\text{ accepts}]\le\epsilon.$$ By the Two-sided Error Reduction theorem from Probabilistic Time Complexity 2 (proved with Hoeffding’s inequality), the constant $\tfrac13$ can be replaced by any constant in $(0,\tfrac12)$, or even by $2^{-\mathrm{poly}(n)}$.

The next class is not covered in CS455. It is like $\mathsf{BPP}$, except that it does not require a gap between yes-instances and no-instances.

Definition ($\mathsf{PP}$, probabilistic polynomial time; Gill 1977)

$L\in\mathsf{PP}$ if there is a polynomial-time PTM $M$ such that $$\forall x\in L,\quad \Pr[M(x)\text{ accepts}] > \tfrac12, \qquad\qquad \forall x\notin L,\quad \Pr[M(x)\text{ accepts}]\le\tfrac12 .$$

Recall that getting error exactly $\tfrac12$ is easy: just output $\mathrm{Bern}(1/2)$. A $\mathsf{PP}$ machine only has to do a tiny bit better than that, and only on yes-instances.

Remark ($\mathsf{PP}$ is a majority vote with no margin)

A $\mathsf{BPP}$ machine has to be right by a noticeable margin, so we can run it a few times and take the majority. A $\mathsf{PP}$ machine only has to be right by the smallest possible margin, maybe a single random string out of $2^{p(n)}$. We can't detect a margin that small by sampling. Instead, a $\mathsf{PP}$ machine really decides whether an exponentially large count (the number of accepting random strings) is above a threshold. The standard $\mathsf{PP}$-complete problem is $$\mathrm{MAJSAT} = \{\langle\varphi\rangle : \text{more than half of all assignments satisfy the Boolean formula } \varphi\}.$$ $\mathsf{PP}$ is very powerful. By Toda’s theorem, the whole polynomial hierarchy is contained in $\mathsf{P}^{\mathsf{PP}}$.

Proposition ($\mathsf{BPP}\subseteq\mathsf{PP}\subseteq\mathsf{PSPACE}$)

$$\mathsf{BPP}\subseteq\mathsf{PP}\subseteq\mathsf{PSPACE}.$$

Proof.

If $M$ solves $L$ with error $\tfrac13$, the same $M$ witnesses $L\in\mathsf{PP}$, since $\ge \tfrac23$ implies $>\tfrac12$ and $\le\tfrac13$ implies $\le\tfrac12$.

For $\mathsf{PP}\subseteq\mathsf{PSPACE}$, let $L\in\mathsf{PP}$ via $M(x,r)$ with $r\in\{0,1\}^{p(|x|)}$. We define $M'$ as follows (this is like the proof of trivial derandomization, $\mathsf{BPP}\subseteq\mathsf{EXP}$):

def $M'(x)$:
$\mathit{count} \gets 0$
for all $r\in\{0,1\}^{p(|x|)}$:
run $M(x,r)$; if it accepts: $\mathit{count}\gets\mathit{count}+1$
if $\mathit{count} > 2^{p(|x|)-1}$: accept
else: reject

Each run of $M(x,r)$ takes polynomial time, hence polynomial space, and the same work space is reused for every $r$. Besides that, $M'$ stores the current $r$ ($p(|x|)$ bits) and the counter ($p(|x|)+1$ bits). So $M'$ runs in polynomial space, and it accepts exactly when $\Pr[M(x)\text{ accepts}]>\tfrac12$. ∎

Uniform circuit families

Recall from Boolean Circuits 1 that a Boolean circuit $C_n$ with $n$ inputs is a straight-line program of AND, OR and NOT instructions, and that a circuit family $\mathcal C = (C_0, C_1, C_2,\dots)$ has one circuit for each input length. In Boolean Circuits 2 we saw that this model is non-uniform: any sparse language, even an undecidable one, can be hard-coded into a circuit family. That is why $\mathsf{P}\subsetneq\mathsf{P}/\mathsf{poly}$. To use circuits as a model of algorithms, we have to rule this out by requiring that the circuits be easy to construct.

Definition (Polynomial-time uniform circuit family)

A circuit family $\mathcal C = (C_0,C_1,C_2,\dots)$ is polynomial-time uniform if there is a deterministic TM that, on input $1^n$, outputs a description of $C_n$ (the list of its gates and the wires each gate acts on) in time polynomial in $n$. In particular, $C_n$ has $\mathrm{poly}(n)$ gates.

We will use the same definition for quantum circuits (see the definition of $\mathsf{BQP}$). The only difference is which gates are allowed. The circuit families we get from Turing machines are uniform:

Theorem (Efficient TM to efficient uniform circuit)

Let $V$ be a TM that runs in polynomial time and outputs one bit. Then there is a polynomial-time uniform circuit family $\mathcal D = (D_0, D_1, \dots)$ with gates AND, OR, NOT of fan-in at most $2$, such that $D_N(w) = V(w)$ for every $N$ and every $w\in\{0,1\}^N$.

Remark (Omitted details)

This is the Efficient TM to Efficient Circuit theorem from Boolean Circuits 1 ($\mathsf{P}\subseteq\mathsf{P}/\mathsf{poly}$), plus the observation that its circuits can be printed efficiently. Each cell of the $t(N)\times t(N)$ computation tableau is computed from the cells above it by a constant-size circuit, and the wiring is regular enough that a TM can output $D_N$ in time $\mathrm{poly}(N)$. See Sipser, Introduction to the Theory of Computation (3rd ed.), Section 9.3, or Arora–Barak, Computational Complexity: A Modern Approach, Chapter 6.

Summary

  • Quantum states will be unit vectors, where $\|v\|^2 = \sum_i |v_i|^2$.
  • $u\otimes v$ has one coordinate $u_iv_j$ for every pair $(i,j)$. The tensor product of two basis vectors is a basis vector, and $(A\otimes B)(u\otimes v) = Au\otimes Bv$.
  • $\mathsf{PP}$ means “accept with probability more than $\tfrac12$ exactly on yes-instances”, with no gap required. It is really about comparing exponentially large counts, and it is contained in $\mathsf{PSPACE}$.
