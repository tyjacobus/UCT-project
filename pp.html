The Main Theorem: $\mathsf{BQP}\subseteq\mathsf{PSPACE}$

In this chapter we prove that a normal computer can simulate a quantum computer using only polynomial space.

The theorem

Theorem (Main Theorem; Bernstein and Vazirani 1993)

$\mathsf{BQP}\subseteq\mathsf{PSPACE}$.

A quantum state on $m$ qubits has $2^m$ amplitudes so we can't represent the whole state. The idea will be not to represent the state but instead just find the the probability that the circuit accepts, finding this one path at a time.

Setup

Let $L\in\mathsf{BQP}$, solved by a uniform circuit family $C_0, C_1,\dots$ over $\mathcal G$ (see definition). Fix an input $x$ of length $n$ and let $C = C_n$. Let $m$, $T$ and $h$ be the number of qubits, gates and Hadamard gates in $C$. m, T, and h are all polynomials. The circuit starts in the state $\ket z$, where $z = x0^{m-n}$, and it accepts if the last qubit reads $1$. So $$p_C(x) = \sum_{y:\,y_m=1}\amp{y}{C}{z}^2 .$$

Amplitudes are signed counts of paths

A classical gate ($X$, CNOT, Toffoli) sends a string of bits to one new string. A Hadamard gate splits it into two (see the Hadamard Formula). So a path through the circuit is fixed by which way it goes at each Hadamard, which is a string $b\in\{0,1\}^h$. The procedure below follows one path.

Definition ($\mathrm{Follow}$)
def $\mathrm{Follow}(z, b)$:
$w \gets z$; $\ \varphi\gets 0$; $\ i\gets 0$
for each gate of $C$, in order:
if $X$ on qubit $j$: $\ w_j\gets 1-w_j$
if CNOT with control $c$, target $j$: $\ w_j\gets w_j\oplus w_c$
if Toffoli with controls $c,c'$, target $j$: $\ w_j\gets w_j\oplus(w_c\wedge w_{c'})$
if $H$ on qubit $j$: $\ i\gets i+1$; $\ \varphi\gets\varphi\oplus(w_j\wedge b_i)$; $\ w_j\gets b_i$
return $(w,\varphi)$

$w$ is where the path ends, and $\varphi$ says its sign: $+$ if $\varphi=0$, $-$ if $\varphi=1$. $\mathrm{Follow}$ runs in polynomial time and space.

Lemma (Path-Sum Lemma)

$$C\ket z = \frac{1}{2^{h/2}}\sum_{b\in\{0,1\}^h}(-1)^{\varphi(b)}\ket{w(b)},$$ where $(w(b),\varphi(b)) = \mathrm{Follow}(z,b)$.

So for every $y$, $\amp yCz = A_y/2^{h/2}$, where $A_y$ is the number of positive paths ending at $y$ minus the number of negative paths ending at $y$.

Proof. We go through the gates one at a time and check that the formula stays true. Before any gates, there is one path (the empty $b$) at $z$ with sign $+$, and the state is $\ket z$.
  • Classical gate: It sends each $\ket w$ to a single $\ket{w'}$ (see definition), where $w'$ is exactly what the matching line of $\mathrm{Follow}$ computes. So each path moves to $w'$ and keeps its sign.
  • Hadamard on qubit $j$: We use the the Hadamard Formula and to show the following: $$\ket w\;\mapsto\;\tfrac{1}{\sqrt2}\sum_{c\in\{0,1\}}(-1)^{w_j c}\ket{w[j\gets c]}.$$ So each path splits in two, one for each new bit $c$. Each half picks up a factor $\tfrac1{\sqrt2}$, and a minus sign exactly when $w_j = c = 1$. That is the $H$ line of $\mathrm{Follow}$, with $c = b_i$.
After all $T$ gates, there is one term for each $b\in\{0,1\}^h$, with factor $2^{-h/2}$, sign $(-1)^{\varphi(b)}$ and endpoint $w(b)$. Collecting the terms that end at $y$ gives $\amp yCz = A_y/2^{h/2}$. ∎

Proof of the Main Theorem

By the lemma, $p_C(x) = \sum_{y_m=1}\big(A_y/2^{h/2}\big)^2 = S/2^h$, where $S = \sum_{y_m=1}A_y^2$. So the circuit accepts with probability more than $\tfrac12$ exactly when $S>2^{h-1}$. M finds this $S$:

def $M(x)$:
build $C = C_{|x|}$. set $z\gets x0^{m-|x|}$, $\ S\gets 0$
for all $y\in\{0,1\}^m$ with $y_m = 1$:
$A\gets 0$
for all $b\in\{0,1\}^h$:
$(w,\varphi)\gets\mathrm{Follow}(z,b)$; if $w = y$: $\ A\gets A + (-1)^{\varphi}$
$S\gets S + A^2$
if $S > 2^{h-1}$: accept; else: reject
Proof.

Correctness. Fix one $y$ with $y_m=1$. The inner loop runs $\mathrm{Follow}$ on every path $b$. It adds $+1$ for each positive path that ends at $y$ and subtracts $1$ for each negative path that ends at $y$, ignoring all other paths. So when the inner loop finishes, $A$ is exactly $A_y$, the signed count from the Path-Sum Lemma.

The outer loop then adds $A_y^2$ to $S$ for every $y$ with last bit $1$. So at the end, we have: $$S = \sum_{y:\,y_m=1}A_y^2 = 2^h\sum_{y:\,y_m=1}\Big(\frac{A_y}{2^{h/2}}\Big)^2 = 2^h\sum_{y:\,y_m=1}\amp yCz^2 = 2^h\,p_C(x).$$ Basically $S$ is the acceptance probability scaled up by $2^h$. So comparing $S$ with $2^{h-1}$ is the same as comparing $p_C(x)$ with $\tfrac12$:

  • If $x\in L$, the circuit accepts with probability $p_C(x)\ge\tfrac23$. Then $S\ge\tfrac23\cdot 2^h > \tfrac12\cdot 2^h = 2^{h-1}$, so $M$ accepts.
  • If $x\notin L$, the circuit accepts with probability $p_C(x)\le\tfrac13$. Then $S\le\tfrac13\cdot 2^h < 2^{h-1}$, so $M$ rejects.

Space Complexity. $M$ only stores the circuit, the loop variables $y$ and $b$ ($m$ and $h$ bits), the counters $A$ and $S$. This fits in $m+2h+2$ bits, since $|A_y|\le 2^h$ as well the space required for $\mathrm{Follow}$ which is reused every time. All of this is polynomial in $n$. This is the same idea as the proof that $\mathsf{BPP}\subseteq\mathsf{PSPACE}$. ∎

Consequences

Corollary (Consequences)
  1. $\mathsf{P}\subseteq\mathsf{BPP}\subseteq\mathsf{BQP}\subseteq\mathsf{PSPACE}$.
  2. If $\mathsf{BPP}\ne\mathsf{BQP}$, then $\mathsf{P}\ne\mathsf{PSPACE}$.
Proof. (1) Combine $\mathsf{BPP}\subseteq\mathsf{BQP}$ with the Main Theorem. (2) If $\mathsf{P}=\mathsf{PSPACE}$, then everything in the chain in (1) equals $\mathsf{P}$, so $\mathsf{BPP}=\mathsf{BQP}$. ∎
Remark (A stronger result, without proof)

Adleman, DeMarrais and Huang (1997) showed $\mathsf{BQP}\subseteq\mathsf{PP}$, where $\mathsf{PP}$ is the class of problems a polynomial-time randomized machine can solve if it has to be right with probability more than $\tfrac12$. Note that $\mathsf{PP}\subseteq\mathsf{PSPACE}$.

Summary

  • Each path through a circuit is a string $b\in\{0,1\}^h$. Running $\mathrm{Follow}$ can find the endpoint of the path and sign in poly time.
  • An amplitude is a signed count of paths, so the acceptance probability is $2^{-h}\sum_{y_m=1}A_y^2$.
  • Adding this up one path can be done in polynomial space. So $\mathsf{BQP}\subseteq\mathsf{PSPACE}$.
