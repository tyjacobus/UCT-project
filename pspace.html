$\mathsf{BQP}\subseteq\mathsf{PSPACE}$

We now turn to the other side of the sandwich: limits on what quantum computers can do. In this chapter we prove that $\mathsf{BQP}\subseteq\mathsf{PSPACE}$. Along the way we prove the Path-Sum Lemma, which says that every amplitude is a signed count of computation paths. The same lemma drives the proof of the Main Theorem in the next chapter.

Guiding Question

Can a classical computer simulate a quantum computer without writing down all $2^m$ amplitudes?

The goal, and the obvious approach

Fix $L\in\mathsf{BQP}$, decided by a uniform circuit family $\mathcal C = (C_0, C_1, \dots)$ over $\mathcal G$ (see definition). On input $x$ of length $n$, a classical simulator must decide whether $p_{C_n}(x)\ge\tfrac23$ or $p_{C_n}(x)\le\tfrac13$. Write $m$, $T$, $h$ for the number of qubits, gates and Hadamard gates of $C_n$. All three are polynomial in $n$. Throughout this chapter and the next, write $$z = x0^{m-n}\quad\text{for the initial basis string, so that}\quad p_{C_n}(x) = \sum_{y:\,y_m=1}\big|\amp{y}{C_n}{z}\big|^2 \qquad(\text{the definition of acceptance probability}).$$

The obvious approach is to do what the quantum computer “does”: store all $2^m$ amplitudes and multiply the vector by each gate (Schrödinger-style simulation). The arithmetic can even be done exactly, since after $t$ gates, $h_t$ of which are Hadamards, every amplitude is an integer multiple of $2^{-h_t/2}$. This shows $\mathsf{BQP}\subseteq\mathsf{EXP}$, but it uses $2^m$ space: the universe-sized vector of the remark on exponentially many amplitudes really is being written down. To do better we use Feynman-style simulation: never store the state, and compute one amplitude at a time as a sum over paths (see lemma), keeping only the current path in memory. This is the same time-for-space trade as in Savitch’s theorem: recompute instead of remember.

The path-sum lemma

The Sum-over-Paths Lemma writes an amplitude as a sum over sequences $z_0\to z_1\to\dots\to z_T$ of $m$-bit strings, but nearly all of those sequences have weight $0$. For our gate set we can say exactly which paths are nonzero: a classical gate sends a basis string to one basis string (see definition), and a Hadamard on qubit $j$ sends it to two, one for each value $c$ of the new bit $j$, with weight $(-1)^{w_j c}/\sqrt2$ (see lemma). So a nonzero path is determined by the $h$ bits chosen at the Hadamard gates, and its sign records how many times a Hadamard went from $1$ to $1$. The following classical procedure follows one such path.

Definition (The path-following procedure $\mathrm{Follow}$)

Let $C$ be a circuit over $\mathcal G$ on $m$ qubits with gates $g_1,\dots,g_T$, of which $h$ are Hadamard gates. For a start string $z\in\{0,1\}^m$ and a choice string $b\in\{0,1\}^h$, define $\mathrm{Follow}(z,b) = (w,\varphi)$ by:

def $\mathrm{Follow}(z, b)$:
$w \gets z$; $\ \varphi\gets 0$; $\ i\gets 0$
for $t = 1,\dots,T$:
if $g_t = X$ on qubit $j$: $\ w_j\gets 1-w_j$
if $g_t = \CNOT$ with control $c$, target $j$: $\ w_j\gets w_j\oplus w_c$
if $g_t = \TOF$ with controls $c,c'$, target $j$: $\ w_j\gets w_j\oplus(w_c\wedge w_{c'})$
if $g_t = H$ on qubit $j$: $\ i\gets i+1$; $\ \varphi\gets\varphi\oplus(w_j\wedge b_i)$; $\ w_j\gets b_i$
return $(w,\varphi)$

We write $w(z,b)$ and $\varphi(z,b)$ for the two outputs: the path's endpoint and its sign bit. $\mathrm{Follow}$ runs in time $O(T+m)$ and space $O(m+\log T)$, given $C$.

In words: $b_i$ is the output bit chosen at the $i$-th Hadamard ("which branch did the path take?"), $w$ is where the path currently is, and $\varphi$ is the parity of the number of $1\to1$ Hadamard steps, the negative edges in the tree of the path tree of $HH\ket0$.

Lemma (Path-Sum Lemma; cf. Dawson et al. 2005)

For every circuit $C$ over $\mathcal G$ with $h$ Hadamard gates and every $z\in\{0,1\}^m$, $$C\ket z \;=\; \frac{1}{2^{h/2}}\sum_{b\in\{0,1\}^h}(-1)^{\varphi(z,b)}\,\ket{w(z,b)} .$$ Equivalently, for every $y\in\{0,1\}^m$: $\displaystyle\amp{y}{C}{z} = \frac{1}{2^{h/2}}\sum_{b\,:\,w(z,b) = y}(-1)^{\varphi(z,b)}$.

Proof. We prove a stronger statement by induction on the number of gates. For $0\le t\le T$, let $C_t = U_t\cdots U_1$ be the first $t$ gates, let $h_t$ be the number of Hadamards among them, and let $\mathrm{Follow}_t(z,b) = (w_t(z,b),\varphi_t(z,b))$ be the result of running $\mathrm{Follow}$ through gate $t$ only, with $b\in\{0,1\}^{h_t}$. We claim $$C_t\ket z = 2^{-h_t/2}\sum_{b\in\{0,1\}^{h_t}}(-1)^{\varphi_t(z,b)}\ket{w_t(z,b)}. \tag{$\ast$}$$ The case $t=T$ is the lemma.

Base case, $t=0$. $C_0 = I$ and $h_0=0$. The sum has a single term (the empty $b$) with $\varphi=0$ and $w = z$, so both sides equal $\ket z$.

Step, when $g_{t+1}$ is a classical gate ($X$, CNOT or TOF). By the definition of applying a gate to chosen qubits and the definition of classical gates, $U_{t+1}\ket w = \ket{w'}$, where $w'$ is $w$ updated exactly as in the $X$, CNOT and TOF lines of $\mathrm{Follow}$. Apply $U_{t+1}$ to $(\ast)$ term by term (linearity): each $\ket{w_t(z,b)}$ becomes $\ket{w_{t+1}(z,b)}$, while $h_{t+1} = h_t$ and $\varphi_{t+1} = \varphi_t$. That gives $(\ast)$ for $t+1$.

Step, when $g_{t+1} = H$ on qubit $j$. By the definition of applying a gate to chosen qubits and the Hadamard Formula, for every string $w$, $$U_{t+1}\ket w = \frac{1}{\sqrt2}\sum_{c\in\{0,1\}}(-1)^{w_j\cdot c}\,\ket{w[j\gets c]} .$$ Apply this to each term of $(\ast)$: $$C_{t+1}\ket z = \frac{1}{2^{(h_t+1)/2}}\sum_{b\in\{0,1\}^{h_t}}\;\sum_{c\in\{0,1\}}(-1)^{\varphi_t(z,b)\,\oplus\,(w_t(z,b)_j\,\wedge\, c)}\;\ket{w_t(z,b)[j\gets c]}.$$ Now rename the pair $(b,c)$ as one string $b' = bc\in\{0,1\}^{h_t+1}$. The $H$ line of $\mathrm{Follow}$ does exactly this at the $(h_t+1)$-th Hadamard: it reads $c = b'_{h_t+1}$, updates $\varphi\gets\varphi\oplus(w_j\wedge c)$, and sets $w_j\gets c$. So the sign and the basis state of the $b'$ term are $(-1)^{\varphi_{t+1}(z,b')}$ and $\ket{w_{t+1}(z,b')}$, and $h_{t+1} = h_t+1$. That is $(\ast)$ for $t+1$.

Finally, the "equivalently" form comes from collecting the terms of the sum by their endpoint $w(z,b)$. ∎

Corollary (Signed Counts)

For every $y$, $\amp{y}{C}{z} = A_y/2^{h/2}$, where $$A_y \;=\; \#\{b: w(z,b)=y,\ \varphi(z,b)=0\} \;-\; \#\{b: w(z,b)=y,\ \varphi(z,b)=1\}$$ is an integer with $|A_y|\le 2^h$. In words: an amplitude is (up to a fixed scaling) the number of positive paths to $y$ minus the number of negative paths to $y$.

Example ($HH\ket0$ through $\mathrm{Follow}$)

$C = H, H$ on one qubit, so $h=2$ and $b = b_1b_2$. $\mathrm{Follow}(0,b)$: the first $H$ gives $\varphi = 0\wedge b_1 = 0$ and $w = b_1$. The second gives $\varphi = b_1\wedge b_2$ and $w = b_2$.

BQP ⊆ PSPACE

Theorem (Bernstein–Vazirani 1993)

$\mathsf{BQP}\subseteq\mathsf{PSPACE}$.

Proof idea. By the Signed Counts Corollary, the acceptance probability is a sum of squares of signed counts. Each count is a sum of $2^h$ terms, and each term can be computed in polynomial time from $b$ alone. So we evaluate the whole expression with nested loops, reusing space between iterations, just as in the proof that $\mathsf{PP}\subseteq\mathsf{PSPACE}$ (see proposition).

Proof. Let $L\in\mathsf{BQP}$ via $\mathcal C = (C_0,C_1,\dots)$. Fix an input $x$ with $|x|=n$, let $C = C_n$, and let $z = x0^{m-n}$.

Step 1 (a formula for $p_C(x)$). By the definition of acceptance probability and the Signed Counts Corollary, $$p_C(x) = \sum_{y:\,y_m=1}\Big(\frac{A_y}{2^{h/2}}\Big)^2 = \frac{S}{2^h},\qquad\text{where } S = \sum_{y:\,y_m=1}A_y^2 .$$ (Amplitudes are real by the Signed Counts Corollary, so $|\cdot|^2$ is just squaring.) Hence $p_C(x)>\tfrac12$ if and only if $S>2^{h-1}$.

Step 2 (the algorithm). We define $M'$ as follows:

def $M'(x)$:
compute $C = C_{|x|}$ (uniformity); read off $m, T, h$; set $z\gets x0^{m-|x|}$
$S\gets 0$
for all $y\in\{0,1\}^m$ with $y_m = 1$:
$A\gets 0$
for all $b\in\{0,1\}^h$:
$(w,\varphi)\gets\mathrm{Follow}(z,b)$
if $w = y$: $\ A\gets A + (-1)^{\varphi}$
$S\gets S + A^2$
if $S > 2^{h-1}$: accept
else: reject

Correctness. By the Signed Counts Corollary, the inner loop leaves $A = A_y$, so at the end $S = \sum_{y_m=1}A_y^2 = 2^h p_C(x)$. If $x\in L$ then $p_C(x)\ge\tfrac23>\tfrac12$ and we accept. If $x\notin L$ then $p_C(x)\le\tfrac13$ and we reject.

Space. The description of $C$ takes $\mathrm{poly}(n)$ bits. The loop variables $y$ and $b$ take $m$ and $h$ bits. Each call to $\mathrm{Follow}$ uses $O(m+\log T)$ bits, and the same space is reused by every call. Since $|A|\le 2^h$, the counter $A$ needs $h+2$ bits. Since $S\le 2^{m-1}\cdot 2^{2h}$, $S$ needs at most $m+2h$ bits. All of this is polynomial in $n$, so $L\in\mathsf{PSPACE}$. (The running time is about $2^{m+h}\cdot\mathrm{poly}(n)$, which is exponential, but that's allowed.) ∎

Remark (Why this works)

We never need the whole state, only one number $p_C(x)$, which is a sum of terms we can produce one at a time. Each term is cheap, because between Hadamards a circuit over $\mathcal G$ is just a reversible Boolean circuit. And an exponential sum fits in polynomial space as long as we add terms as we go, exactly as in $\mathsf{PP}\subseteq\mathsf{PSPACE}$. The exponential size of the quantum state is a time cost for the simulator, not a space cost.

Looking ahead

The quantity we computed, $S = \sum_{y_m=1}A_y^2$, is built from counts of polynomial-time checkable objects, which is what $\mathsf{PP}$ is good at (see remark). The one obstacle to a $\mathsf{PP}$ simulation is the square. A probabilistic machine's acceptance probability is a linear function of path counts, but $S$ is quadratic in the $A_y$. The fix is to expand the square, which turns a sum over paths into a sum over pairs of paths (the pairs exercise). That is the starting point of the proof of the Main Theorem in the next chapter.

Exercises

Exercise (Preview of the Two-Path Lemma)

Show that $\displaystyle S = \sum_{b,b'\in\{0,1\}^h}\big[w(z,b) = w(z,b')\text{ and }w(z,b)_m = 1\big]\,(-1)^{\varphi(z,b)+\varphi(z,b')}$, where $[\cdot]$ is $1$ if the condition holds and $0$ otherwise.

By the Signed Counts Corollary, $A_y = \sum_b[w(z,b)=y](-1)^{\varphi(z,b)}$, so $A_y^2 = \sum_{b,b'}[w(z,b)=y]\,[w(z,b')=y]\,(-1)^{\varphi(z,b)+\varphi(z,b')}$. Sum over $y$ with $y_m=1$ and swap the order of summation. For a fixed pair $(b,b')$, the only $y$ that can contribute is $y = w(z,b)$, and it does so exactly when $w(z,b') = w(z,b)$ and $w(z,b)_m = 1$.

Summary

  • Path-sum lemma: over $\mathcal G$, $\amp yCz = 2^{-h/2}\sum_{b:\,w(z,b)=y}(-1)^{\varphi(z,b)}$. A path is a choice string $b$, and $\mathrm{Follow}$ computes its endpoint and sign in polynomial time.
  • An amplitude is a signed count: #positive paths minus #negative paths, times $2^{-h/2}$.
  • Schrödinger simulation uses $2^m$ space. Feynman simulation adds the paths one at a time in polynomial space, so $\mathsf{BQP}\subseteq\mathsf{PSPACE}$.
