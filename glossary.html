Definitions (alphabetical)

Acceptance probability $p_C(x)$
$\sum_{y_m=1}|\amp{y}{C}{x0^{m-n}}|^2$. Definition 6.1
Amplitude
A coordinate of a quantum state; $\braket z\psi$. Definition 3.1, Definition 3.4
Bell state $\ket{\Phi^+}$
$\tfrac1{\sqrt2}(\ket{00}+\ket{11})$, an entangled state. Proposition 3.9, Example 4.9
BPP
Bounded-error probabilistic polynomial time. Definition 2.4
BQP
Bounded-error quantum polynomial time: uniform circuits over $\mathcal G$ with $p\ge\frac23$ on yes-instances and $\le\frac13$ on no-instances. Definition 6.2
Classical (permutation) gate
A gate that maps each basis state to a basis state; $X$, CNOT, TOF. Definition 4.8
CNOT, Toffoli
$\ket{a,b}\mapsto\ket{a,b\oplus a}$; $\ket{a,b,c}\mapsto\ket{a,b,c\oplus ab}$. Definition 4.7
Quantum circuit
A sequence of gates; computes $C = U_T\cdots U_1$. Definition 4.10
Entangled / product state
Product: $\ket a\otimes\ket b$; entangled: not a product. Definition 3.8
Follow
The classical path-following procedure. Definition 8.2
Gate set $\mathcal G$
$\{H,X,\CNOT,\TOF\}$. Definition 4.11; universality: Fact 4.12
Gate applied to chosen qubits
$G_{[j_1..j_k]}$ acts on the chosen bits and carries the rest along. Definition 4.6
Hadamard gate $H$; Hadamard formula
$H\ket a = \tfrac{1}{\sqrt2}\sum_c(-1)^{ac}\ket c$. Definition 4.3, Lemma 4.4
Hadamard transform
$H^{\otimes n}\ket x = 2^{-n/2}\sum_y(-1)^{x\cdot y}\ket y$. Lemma 4.13
Inner product, norm, conjugate transpose
Definition 2.1
Interference
Cancellation (destructive) or reinforcement (constructive) of path weights that end at the same basis state. Lemma 5.3, Remark 5.6
Measurement (Born rule)
Outcome $z$ with probability $|\braket z\psi|^2$; one qubit: $\sum_{z_j=1}|\braket z\psi|^2$. Definition 3.2, Definition 3.6
Oracle gate, query algorithm
Definition 7.1; phase kickback: Lemma 7.2
Path-sum lemma
$C\ket z = 2^{-h/2}\sum_b(-1)^{\varphi(z,b)}\ket{w(z,b)}$. Lemma 8.3
PP
Probabilistic polynomial time: accept with probability $>\frac12$ exactly on yes-instances. Definition 2.5
Qubit; $m$-qubit state
A unit vector in $\C^2$; in $\C^{2^m}$. Definition 3.1, Definition 3.4
Reversible simulation; uncomputation
Lemma 6.4, Lemma 6.5
Signed counting ("abstain" trick)
Lemma 9.2
Stochastic matrix
Definition 5.1
Sum over paths
Lemma 5.3
Tensor product
Definition 2.2, Fact 2.3
Two-path formula
$2p_C(x)-1 = 2^{-h}\sum_{b,b'}v(b,b')$. Lemma 9.3
Uniform circuit family
Definition 2.7
Unitary matrix
$U^\dagger U = I$; equivalently norm-preserving. Definition 4.1, Fact 4.2
