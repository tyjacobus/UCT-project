Qubits and Quantum States

The "memory" of a quantum computer, and what you can and cannot read out of it.

Where this page sits. This is the first page of the model. It defines the states of a quantum computer; Page 4 defines the operations on them.
  • You will learn: qubits and Dirac notation, measurement, multi-qubit states, entanglement, and why $m$ qubits take $2^m$ numbers to describe.
  • Used later: the notation $\ket z$ and $\braket{z}{\psi}$ (Definition 3.4), and the measurement rule (Definition 3.6) on every later page.

§1From bits to qubits

It helps to describe a classical bit in a slightly roundabout way. A random bit that is $0$ with probability $p_0$ and $1$ with probability $p_1$ can be written as a vector $$\begin{pmatrix}p_0\\p_1\end{pmatrix},\qquad p_0,p_1\ge 0,\quad p_0+p_1 = 1.$$ A deterministic bit is the special case $(1,0)^T$ or $(0,1)^T$. A qubit is what you get when you allow the entries to be arbitrary (possibly negative, possibly complex) numbers, and change the normalization from "entries sum to $1$" to "squared magnitudes sum to $1$."

Definition 3.1 (Qubit; Dirac notation)

A qubit (the state of a single quantum bit) is a unit vector in $\C^2$. We name the two standard basis vectors $$\ket 0 = \begin{pmatrix}1\\0\end{pmatrix}, \qquad \ket 1 = \begin{pmatrix}0\\1\end{pmatrix},$$ so a general qubit is $$\ket\psi = \alpha\ket0 + \beta\ket1 = \begin{pmatrix}\alpha\\\beta\end{pmatrix}, \qquad \alpha,\beta\in\C,\quad |\alpha|^2+|\beta|^2 = 1.$$ The numbers $\alpha,\beta$ are called amplitudes. The notation $\ket{\cdot}$ ("ket") just means "the column vector named $\cdot$."

We can never look at the amplitudes directly. All we can do is measure:

Definition 3.2 (Measuring a qubit: the Born rule)

Measuring the qubit $\alpha\ket0+\beta\ket1$ gives outcome $0$ with probability $|\alpha|^2$ and outcome $1$ with probability $|\beta|^2$. Afterwards the qubit is in state $\ket 0$ or $\ket 1$ respectively, matching the outcome. (Measuring "collapses" the state.)

Example 3.3 ($\ket+$ and $\ket-$)

Two qubit states will come up constantly: $$\ket+ = \tfrac{1}{\sqrt2}\ket0 + \tfrac1{\sqrt2}\ket1, \qquad \ket- = \tfrac1{\sqrt2}\ket0 - \tfrac1{\sqrt2}\ket1.$$ Measuring either one gives $0$ or $1$ with probability $\big(\tfrac1{\sqrt2}\big)^2 = \tfrac12$ each. As far as a direct measurement can tell, both are just fair coins. But they are different states, and on Page 4 we'll apply one gate ($H$) that turns $\ket+$ into $\ket0$ and $\ket-$ into $\ket1$, so the difference becomes perfectly visible. The sign of an amplitude is invisible to a measurement, but it is not meaningless: it changes what happens later. That is the whole game.

Remark (global sign)

Multiplying an entire state by $-1$ (or by any complex number of modulus 1) changes nothing observable, now or later, because every measurement probability is a squared magnitude and every later operation is linear. So $\ket\psi$ and $-\ket\psi$ are physically the same. Only relative signs between amplitudes matter, as in $\ket+$ versus $\ket-$.

§2Many qubits

A classical $m$-bit register holds one string $z\in\{0,1\}^m$. A random register is a probability distribution over the $2^m$ strings. A quantum register is an amplitude vector over the $2^m$ strings:

Definition 3.4 ($m$-qubit state; amplitude notation)

An $m$-qubit state is a unit vector in $\C^{2^m}$ whose coordinates are indexed by strings $z\in\{0,1\}^m$ (in lexicographic order). The standard basis vector for $z$ is written $\ket z$, and is called a computational basis state. A general state is $$\ket\psi = \sum_{z\in\{0,1\}^m}\alpha_z\ket z,\qquad \sum_z|\alpha_z|^2 = 1.$$ We write $\braket{z}{\psi} := \alpha_z$ for the amplitude of $\ket z$ in $\ket\psi$. We number the qubits $1,\dots,m$ from left to right, and say that in the basis state $\ket z$, qubit $j$ holds the bit $z_j$.

(Formally, $\bra z$ is the row vector $\ket z^\dagger$, so $\braket z\psi$ is the inner product of Definition 2.1. On this site you only need "the $z$-th coordinate.")

How does this relate to single qubits? By the tensor product (Definition 2.2). Since tensoring basis vectors gives basis vectors in lexicographic order (Fact 2.3), we get:

Fact 3.5 (Side by side = tensor product)

$\ket{z_1}\otimes\ket{z_2}\otimes\cdots\otimes\ket{z_m} = \ket{z_1z_2\cdots z_m}$. More generally, if qubits $1..k$ are in state $\ket\psi$ and qubits $k{+}1..m$ are independently in state $\ket\phi$, the whole register is in state $\ket\psi\otimes\ket\phi$. We often drop the $\otimes$ and write $\ket\psi\ket\phi$, so for example $\ket x\ket{0^{m-n}} = \ket{x0^{m-n}}$.

Example

$\ket+\otimes\ket0 = \tfrac1{\sqrt2}(\ket0+\ket1)\otimes\ket0 = \tfrac1{\sqrt2}\ket{00} + \tfrac1{\sqrt2}\ket{10}$, by bilinearity. The first qubit is a "quantum coin" and the second is a definite $0$.

Definition 3.6 (Measuring several qubits, or just one)

Let $\ket\psi = \sum_z \alpha_z\ket z$.

  • Measuring all $m$ qubits gives outcome $z$ with probability $|\alpha_z|^2$.
  • Measuring only qubit $j$ gives outcome $1$ with probability $$\Pr[\text{qubit } j \text{ reads } 1] = \sum_{z\,:\,z_j = 1}|\alpha_z|^2,$$ and $0$ with the remaining probability. (Afterwards the amplitudes with $z_j$ different from the outcome are set to $0$ and the state is rescaled to have norm $1$. We won't need the post-measurement state, because we only measure at the very end of a computation.)

The second rule is consistent with the first: measuring qubit $j$ alone gives $1$ with the same probability as "measure everything and look at bit $j$."

Example 3.7

Let $\ket\psi = \tfrac1{\sqrt3}\big(\ket{00}+\ket{01}+\ket{11}\big)$. Measuring both qubits gives $00$, $01$, $11$ with probability $1/3$ each, and never $10$. Measuring only qubit 1 gives $1$ with probability $|\alpha_{10}|^2+|\alpha_{11}|^2 = 0+\tfrac13 = \tfrac13$. Measuring only qubit 2 gives $1$ with probability $|\alpha_{01}|^2+|\alpha_{11}|^2 = \tfrac23$.

§3Entanglement

Not every multi-qubit state is built by placing single qubits side by side.

Definition 3.8 (Product states and entanglement)

A two-qubit state $\ket\psi$ is a product state if $\ket\psi = \ket a\otimes\ket b$ for some single-qubit states $\ket a,\ket b$. Otherwise it is entangled. (The same definition applies to any split of a register into two parts.)

Proposition 3.9 (The Bell state is entangled)

The Bell state $\ket{\Phi^+} = \tfrac1{\sqrt2}\ket{00} + \tfrac1{\sqrt2}\ket{11}$ is entangled.

Proof. Suppose $\ket{\Phi^+} = (a_0\ket0+a_1\ket1)\otimes(b_0\ket0+b_1\ket1)$. Expanding by bilinearity, $$(a_0\ket0+a_1\ket1)\otimes(b_0\ket0+b_1\ket1) = a_0b_0\ket{00} + a_0b_1\ket{01} + a_1b_0\ket{10} + a_1b_1\ket{11}.$$ Comparing coefficients: $a_0b_0 = \tfrac1{\sqrt2}\neq0$, so $a_0\ne0$. And $a_1b_1 = \tfrac1{\sqrt2}\ne 0$, so $b_1\ne0$. Hence $a_0b_1\ne 0$. But the coefficient of $\ket{01}$ in $\ket{\Phi^+}$ is $0$. That's a contradiction. ∎

What does entanglement look like operationally? Measuring both qubits of $\ket{\Phi^+}$ gives $00$ or $11$, each with probability $\tfrac12$. The two bits are random but perfectly correlated, and neither qubit on its own can be described by a single-qubit state. On Page 4 we'll build $\ket{\Phi^+}$ from $\ket{00}$ with two gates. On Page 5 we'll see the downside of entanglement for algorithm design: if your answer qubit is entangled with leftover "garbage," it can no longer interfere.

§4Exponentially many amplitudes

Remark 3.10 ($2^m$ numbers, but only $m$ bits out)

A product state of $m$ qubits is described by $2m$ amplitudes. A general (entangled) state needs all $2^m$. With $m=300$ that is more numbers than there are atoms in the observable universe (about $10^{80}$). This is Feynman's observation: writing down the state of a quantum system on a classical computer seems to take exponential resources.

Two caveats keep this from being "exponential power for free":

  1. Output is tiny. A measurement returns a single $m$-bit string, sampled at random. You can't read the $2^m$ amplitudes. (Holevo's theorem makes this precise: $m$ qubits can be used to transmit at most $m$ classical bits of information; see Nielsen–Chuang, §12.1.)
  2. Simulation doesn't need to store everything. On Page 8 we compute any single measurement probability without ever writing down the $2^m$-entry vector, using only polynomial space. That is the first step toward the centerpiece theorem.

Exercises

Exercise 3.A Let $\ket\psi = \tfrac12\ket{00} - \tfrac12\ket{01} + \tfrac{1}{\sqrt2}\ket{11}$. Check that it is a unit vector. What is the probability that measuring qubit 2 gives $1$?
Show solution

$\tfrac14+\tfrac14+\tfrac12 = 1$, so it is a unit vector. $\Pr[\text{qubit 2 reads }1] = |\alpha_{01}|^2 + |\alpha_{11}|^2 = \tfrac14+\tfrac12 = \tfrac34$. The minus sign plays no role in this measurement.

Exercise 3.B Show that a two-qubit state $\sum_{z}\alpha_z\ket z$ is a product state if and only if $\alpha_{00}\alpha_{11} = \alpha_{01}\alpha_{10}$. Use this to decide whether $\tfrac12(\ket{00}+\ket{01}+\ket{10}+\ket{11})$ and $\tfrac12(\ket{00}+\ket{01}+\ket{10}-\ket{11})$ are entangled.
Show solution

If $\ket\psi = \ket a\otimes\ket b$ then $\alpha_{00}\alpha_{11} = a_0b_0a_1b_1 = \alpha_{01}\alpha_{10}$. Conversely, suppose $\alpha_{00}\alpha_{11}=\alpha_{01}\alpha_{10}$. Then the matrix $\begin{pmatrix}\alpha_{00}&\alpha_{01}\\ \alpha_{10}&\alpha_{11}\end{pmatrix}$ has determinant $0$, so it has rank $1$ (it is nonzero because $\ket\psi$ is a unit vector). So it equals $a\,b^T$ for some vectors $a,b$, which means $\alpha_{ij} = a_ib_j$. Rescale so that $\|a\| = 1$; then $\|b\| = 1$ too, by Fact 2.3(4).

The first state has $\tfrac14 = \tfrac14$, so it is a product state; in fact it is $\ket+\otimes\ket+$. The second has $\alpha_{00}\alpha_{11} = -\tfrac14 \ne \tfrac14 = \alpha_{01}\alpha_{10}$, so it is entangled, even though it differs from a product state by a single sign. We'll meet it again in Example 5.5.

Takeaways
  • An $m$-qubit state is a unit vector of $2^m$ amplitudes $\braket z\psi$, one per classical string $z$.
  • Measurement turns amplitudes into probabilities by squaring magnitudes: $\Pr[z] = |\braket z\psi|^2$.
  • Signs are invisible to measurement right now ($\ket+$ vs. $\ket-$), but they change what happens later.
  • Entangled states (such as the Bell state) are not products of single-qubit states. Describing general states takes $2^m$ numbers, but you only ever get $m$ bits out.
