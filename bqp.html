$\mathsf{BQP}$ and Reversible Computation

We can now finally define $\mathsf{BQP}$ which is just the quantum version of $\mathsf{BPP}$. We will do that and then prove the lower bound part of our result: $\mathsf{P}\subseteq\mathsf{BPP}\subseteq\mathsf{BQP}$.

The class BQP

A quantum algorithm takes as input some $x\in\{0,1\}^n$. It then copies the first $n$ bits into $n$ qubits, seting all the other qubits to $\ket0$, and runs the quantum circuit on these qubits. The last qubit is the answer to our algorithm.

Definition (Acceptance probability)

Let $C$ be a circuit on $m$ qubits and $x\in\{0,1\}^n$ with $n\le m$. To run $C$ on $x$, start in the state $\ket{x0^{m-n}}$, apply the gates of $C$, and meaure qubit $m$. $C$ accepts if the measured qubit is $1$. By the measurement rule, the acceptance probability is $$p_C(x) \;=\; \sum_{y\in\{0,1\}^m:\;y_m = 1}\big|\amp{y}{C}{x0^{m-n}}\big|^2 .$$

Definition ($\mathsf{BQP}$, bounded-error quantum polynomial time; Bernstein–Vazirani 1993)

A quantum circuit family $\mathcal C = (C_0, C_1, C_2,\dots)$ solves a language $L$ with error $\epsilon$ if $$\forall x\in L,\quad \Pr[C_{|x|}(x)\text{ accepts}]\ge 1-\epsilon, \qquad\qquad \forall x\notin L,\quad \Pr[C_{|x|}(x)\text{ accepts}]\le\epsilon,$$ where $\Pr[C(x)\text{ accepts}] = p_C(x)$. Then $$\mathsf{BQP} = \{L \mid \exists \text{ polynomial-time uniform circuit family } \mathcal C \text{ over } \mathcal G \text{ solving } L \text{ with error } \tfrac13\}.$$ As we've discussed already, $\mathcal G = \{H,X,\CNOT,\TOF\}$ is our gate set and polynomial-time uniform means the same thing as for Boolean circuits. (see definition). $C_n$ has $m(n)$ qubits and $T(n)$ gates where $m$ and $T$ are polynomials.

Note that this is the same definition as definition of $\mathsf{BPP}$. The only difference is that the PTM is replaced by a uniform family of quantum circuits.

Remark (Definition details)

Just like with $\mathsf{BPP}$, the error $\tfrac13$ can be lowered to $2^{-\mathrm{poly}(n)}$ with the exact same strategy. We just run several independent copies of $C_n$ on separate qubits and compute the majority of their answers.

Making classical circuits reversible

To prove $\mathsf{P}\subseteq\mathsf{BQP}$, we need to be able to simulate a normal Boolean circuit $D$ on a quantum computer. This means that we have to be able to replicate AND, OR and NOT. The difficulty with this is that as we've seen in this remark, all quantum computation is reversible since we don't ever lose information. However, AND and OR are not reversible. The way we can get around this is by never overwrite any of the qubits during the simulation. Instead, each gate will its output into a new qubit with initial state $\ket0$. For example, we'd compute AND with the Toffoli gate like this: $\TOF\ket{a,b,0} = \ket{a,b,a\wedge b}$.

Lemma (Reversible Simulation Lemma)

Let $D$ be a Boolean circuit with $n$ inputs and $s$ gates (AND, OR, NOT; fan-in at most 2), which computes $g_1(x),\dots,g_s(x)$. There is a circuit $R_D$ over $\{X,\CNOT,\TOF\}$ on $n+s$ qubits with at most $6s$ gates such that for every $x\in\{0,1\}^n$, $$R_D\ket{x}\ket{0^s} = \ket{x}\ket{g(x)},\qquad\text{where } g(x) = g_1(x)\,g_2(x)\cdots g_s(x).$$ This $R_D$ can be computed in poly time.

Proof. First if any AND or OR gate uses the same value $a$ on both of its inputs, the result is always just $a$. So, we can simulate this with a single $\CNOT$ from $a$ into a fresh qubit. For the rest of the proof, we will assume these two inputs are unique. For each gate $i$ of $D$, we will map this to qubit $n+i$, starting at $\ket0$. Iterate through the gates in topological order. When we reach gate $i$, its input wires will already be correct since we've already processed them. Then:
  • $\mathrm{NOT}(a)$: apply $\CNOT$ from $a$ to qubit $n+i$ and $X$ on qubit $n+i$ which negates it.
  • $\mathrm{AND}(a,b)$: apply $\TOF$ with controls $a,b$ and target $n+i$. This computes $0\oplus(a\wedge b) = a\wedge b$.
  • $\mathrm{OR}(a,b) = \neg(\neg a\wedge\neg b)$: we already can compute each of these gates individually. We just need to apply $X$ to $a$ and $b$ then $\TOF$ into $n+i$ then $X$ to $a$ and $b$ again and then $X$ on $n+i$.
At each step, we compute the right result without chaging the input wire. So, by induction on $i$, after gate $i$ the register holds $x,\,g_1(x),\dots,g_i(x),\,0,\dots,0$. $X$, CNOT, and Toffoli each are classical gates since they send a basis state to a single basis state. So, we can always modle the register as just a string of bits. ∎

Although the simulation strategy seen in the Reversible Simulation Lemma works for a normal circuit, it will cause problems when we introduce randomness. This is because we are leaving evidence of the path our circuit took behind. We are creating these garbage bits since we always copy the results into a fresh qubit (seen how $\alpha_x\ket x$ is left in the result): $$R_D\Big(\sum_x\alpha_x\ket x\Big)\ket{0^s} = \sum_x\alpha_x\ket x\ket{g(x)} .$$ This garbage is entangled with $x$ so by the interference principle it stops different values of $x$ that took different paths from cancelling. We will use the Bennett’s trick from 1973 removes the garbage. The trick is to compute and copy the answer and then run the computation backwards.

Lemma (Bennett’s Uncomputation Lemma)

Let $D$ be a Boolean circuit with $n$ inputs and $s$ gates that computes $f:\{0,1\}^n\to\{0,1\}$ (the output is the last gate, so $f = g_s$). There is a circuit $B_D$ over $\{X,\CNOT,\TOF\}$ on $n+s+1$ qubits, with at most $12s+1$ gates and computable from $D$ in polynomial time, such that for all $x\in\{0,1\}^n$ and $b\in\{0,1\}$: $$B_D\,\ket{x}\ket{0^s}\ket{b} \;=\; \ket{x}\ket{0^s}\ket{b\oplus f(x)} .$$

Why this is the equation we want.

  • The output qubit starts at $b=0$ and $0\oplus f(x) = f(x)$ so this is exactly the result we want.
  • No garbage is left since the scratch bits are set back to $0$.
  • The input stays the same keepign it reversible and without any hints of the computation path.

So $B_D$ does exactly what a classical function call should do: it adds $f(x)$ to the output and leaves no other trace.

Proof. Let $B_D = R_D^{-1}\cdot \CNOT_{[n+s,\;n+s+1]}\cdot R_D$, where $R_D$ is the quantum circuit we just constructed in the Reversible Simulation Lemma and $R_D^{-1}$ is the gates of $R_D$ in reverse order. $X$, CNOT and Toffoli is its own inverse so this in total is the inverse. Follow a basis state through the three steps: $$\ket x\ket{0^s}\ket b\;\xrightarrow{\;R_D\;}\;\ket x\ket{g(x)}\ket b\;\xrightarrow{\;\CNOT\;}\;\ket x\ket{g(x)}\ket{b\oplus f(x)}\;\xrightarrow{\;R_D^{-1}\;}\;\ket x\ket{0^s}\ket{b\oplus f(x)}.$$ The first step is the Reversible Simulation Lemma which just computes exactly the function, copying all results into fresh qubits. The second copies the last scratch bit $g_s(x) = f(x)$ into the last qubit. In the third, $R_D^{-1}$ only acts on the first $n+s$ qubits and it is the inverse of the first step so all qubits but the final qubit are reset. The gate count is $6s+1+6s$. ∎

P ⊆ BQP and BPP ⊆ BQP

Theorem ($\mathsf{P}\subseteq\mathsf{BQP}$)

Every language in $\mathsf{P}$ is in $\mathsf{BQP}$.

Proof. Let $L\in\mathsf{P}$. By the Efficient TM to Efficient Circuit theorem, there is a polynomial-time uniform family of Boolean circuits $D_n$ of size $s(n) = \mathrm{poly}(n)$ that decide $L$ on inputs of length $n$. We then just showed that we can use this circuit to make a quantum circuit that simulates it. Let $C_n = B_{D_n}$ from Bennett’s Uncomputation Lemma. Running $C_n$ on $x$ results in the basis state $\ket{x}\ket{0^s}\ket{L(x)}$ which contains no garbage so $L(x) = 1$ if $x\in L$ and $0$ otherwise. So $p_{C_n}(x) = 1$ if $x\in L$ and $0$ otherwise. ∎

Now to compute randomized algorithms, we need to have some source of a coin flip. As we've seen, we can do this with Hadamard. We just need to not let it cancel itself out as we saw when we ran Hadamard twice.

Theorem ($\mathsf{BPP}\subseteq\mathsf{BQP}$)

Every language in $\mathsf{BPP}$ is in $\mathsf{BQP}$. More precisely, for every poly time PTM $M$ there is a poly time uniform circuit family $\mathcal C = (C_0, C_1, \dots)$ over $\mathcal G$ with $p_{C_n}(x) = \Pr[M(x)\text{ accepts}]$ for every $x$.

Proof. We will use the random tape view of an NTM. So, we will assume there is a polynomial $r(n)$ and a deterministic poly time TM $V(x,\rho)$, with $\rho\in\{0,1\}^{r(|x|)}$, such that $\Pr[M(x)\text{ accepts}] = \Pr_{\rho}[V(x,\rho)\text{ accepts}]$. We can then apply the Efficient TM to Efficient Circuit theorem on this TM $V$ to create a uniform Boolean circuits $D_n$ of size $s = \mathrm{poly}(n)$ with $D_n(x,\rho) = V(x,\rho)$.

We will the $m = n + r + s + 1$ qubits into four different sections for simplicity: input $x$ ($n$ qubits), coins ($r$ qubits), scratch ($s$ qubits) and answer ($1$ qubit). Let $C_n$ be:

  1. Run Hadamard on each of the $r$ coin qubits
  2. Get a quantum circuit $B_{D_n}$ from the (Bennett’s Uncomputation Lemma). Then we will run this using the input and coint qubits as its $n+r$ input qubits.

The state will start as $\ket x\ket{0^r}\ket{0^s}\ket0$. By the Uniform Superposition Lemma, step 1 computes $$\frac{1}{2^{r/2}}\sum_{\rho\in\{0,1\}^r}\ket x\ket\rho\ket{0^s}\ket0 .$$ Then since all quantum operations are linear, step 2 gives us $$\frac{1}{2^{r/2}}\sum_{\rho\in\{0,1\}^r}\ket x\ket\rho\ket{0^s}\ket{V(x,\rho)} .$$ Note that since p is part of the state, no results will interfere since each branch in the tree has a different value of p so we have $$p_{C_n}(x) = \sum_{\rho:\,V(x,\rho)=1}\big(2^{-r/2}\big)^2 = \frac{\#\{\rho: V(x,\rho) = 1\}}{2^r} = \Pr[M(x)\text{ accepts}].$$ So the quantum circuit accepts with the exact same probability that M accepts. ∎

This source of randomness worked because we used a different qubit that had been applied with hadamard to get each bit of randomness.

Summary

  • $\mathsf{BQP}$ is defined exactly like $\mathsf{BPP}$, but with a uniform family of quantum circuits over $\mathcal G$ instead of a PTM.
  • Toffoli gates let us make any classical circuit reversible but this leaves garbage that doesn't allow for interference.
  • Bennett’s trick removes the garbage.
